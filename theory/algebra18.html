1. Що ми шукаємо?

У рівнянні \(\sin x=a\) невідомий кут x. Синус відомий, а кут потрібно знайти. Наприклад, \(\sin30^\circ=\frac12\), але також \(\sin150^\circ=\frac12\). Тому одного кута часто недостатньо.

На одиничному колі точка кута x має координати \((\cos x;\sin x)\). Косинус — горизонтальна координата, синус — вертикальна.

💡 Запам’ятайПовний оберт повертає точку на те саме місце. Через це рівняння мають нескінченні сім’ї коренів.

2. Градуси, радіани та періоди

\[180^\circ=\pi,\qquad360^\circ=2\pi\]

Синус і косинус: період \(2\pi\), або 360°. Тангенс і котангенс: період \(\pi\), або 180°.

Запис \(k\in\mathbb Z\) означає, що k — будь-яке ціле число: −2, −1, 0, 1, 2, …

\[30^\circ=\frac\pi6,\quad45^\circ=\frac\pi4,\quad60^\circ=\frac\pi3,\quad90^\circ=\frac\pi2\]

Не змішуй градуси й радіани в одному записі.

3. Рівняння sin x = a

Спочатку перевір можливість розв’язку: \(|a|\le1\). Якщо \(|a|>1\), коренів немає.

Познач \(\alpha=\arcsin a\), де \(-\frac\pi2\le\alpha\le\frac\pi2\). Тоді:

\[x=\alpha+2\pi k\quad\text{або}\quad x=\pi-\alpha+2\pi k,\quad k\in\mathbb Z\]

Одна компактна формула для будь-якого допустимого a:

\[x=(-1)^k\arcsin a+\pi k,\quad k\in\mathbb Z\]

При від’ємному a значення arcsin a вже від’ємне. Додатковий мінус не потрібен.

Покроково: sin x = −1/2
1. \(\alpha=-\frac\pi6\).
2. Перша сім’я: \(x=-\frac\pi6+2\pi k\).
3. Друга: \(x=\pi+\frac\pi6+2\pi k=\frac{7\pi}6+2\pi k\).
4. На [0°; 360°): 210° і 330°. Обидва синуси від’ємні.

4. Особливі значення синуса

\[\sin x=0\Rightarrow x=\pi k\]\[\sin x=1\Rightarrow x=\frac\pi2+2\pi k\]\[\sin x=-1\Rightarrow x=-\frac\pi2+2\pi k\]

Тут і далі \(k\in\mathbb Z\). Для ±1 дві сім’ї загальної формули збігаються — не рахуй їх двічі.

5. Рівняння cos x = a

Корені існують лише при \(|a|\le1\). Познач \(\beta=\arccos a\), де \(0\le\beta\le\pi\).

\[x=\pm\arccos a+2\pi k,\quad k\in\mathbb Z\]

Ця формула підходить і для додатного, і для від’ємного a. Наприклад, \(\arccos(-\frac12)=\frac{2\pi}3\):

\[x=\pm\frac{2\pi}3+2\pi k\]

На [0°; 360°): 120° і 240°.

\[\cos x=0\Rightarrow x=\frac\pi2+\pi k\]\[\cos x=1\Rightarrow x=2\pi k\]\[\cos x=-1\Rightarrow x=\pi+2\pi k\]

6. Тангенс і котангенс

Тангенс: будь-яке дійсне a допустиме.

\[\tan x=a\Rightarrow x=\arctan a+\pi k\]

Тут \(-\frac\pi2<\arctan a<\frac\pi2\). Якщо a від’ємне, arctan a вже від’ємне. Тангенс не визначений при \(x=\frac\pi2+\pi k\).

Котангенс: у цьому модулі \(\operatorname{arccot}a\in(0;\pi)\).

\[\cot x=a\Rightarrow x=\operatorname{arccot}a+\pi k\]

Котангенс не визначений при \(x=\pi k\). Для від’ємного a кут arccot лежить у II чверті.

Приклади: \(\tan x=-1\Rightarrow x=-\frac\pi4+\pi k\); \(\cot x=-1\Rightarrow x=\frac{3\pi}4+\pi k\).

7. Якщо всередині 2x, 3x або x + α

Спочатку розв’яжи рівняння для всього аргументу, потім вирази x.

1. \(\sin(2x)=\frac12\).
2. \(2x=\frac\pi6+2\pi k\) або \(2x=\frac{5\pi}6+2\pi k\).
3. Ділимо ВСІ доданки на 2: \(x=\frac\pi{12}+\pi k\) або \(x=\frac{5\pi}{12}+\pi k\).

Для \(\cos(x-30^\circ)=1\): \(x-30^\circ=360^\circ k\), тому \(x=30^\circ+360^\circ k\).

8. Як відібрати корені на проміжку?

Загальний розв’язок дає всі корені. Якщо задано проміжок, залиш лише ті, що до нього належать.

\(\sin x=\frac12\): x = 30° + 360°k або x = 150° + 360°k.
На [0°; 360°): 30° і 150°. На [0°; 720°): 30°, 150°, 390°, 510°.

Кругла дужка виключає край. Наприклад, для sin x = 0 на [0°; 360°) маємо 0° і 180°; 360° не включаємо.

9. Лайфхаки та типові помилки

🎯 Синус — висота: одна горизонтальна пряма зазвичай перетинає коло у двох точках.

🎯 Косинус — горизонталь: одна вертикальна пряма дає дві точки.

🔁 Для sin і cos додавай 360°, для tan і cot — 180°.

✓ Підстав один знайдений кут у початкове рівняння. Перевір знак та область визначення.

Знайди помилку: sin x = 1, отже x = 90° + 180°k

При k = 1 отримуємо 270°, але синус цього кута −1. Правильно x = 90° + 360°k.

Знайди помилку: tan x = −1, отже x = 45° + 180°k

Тангенс 45° дорівнює +1. Правильно x = −45° + 180°k; рівносильно x = 135° + 180°k.

Лабораторія одиничного кола

Синій відрізок — косинус, помаранчевий — синус. Порівняй 30° і 150°: синус однаковий, косинус має різні знаки.

Тренажер: 18 задач за рівнями

Вводь лише число: кут у градусах або кількість коренів, як зазначено в умові. Наприклад: 30 або 22,5. Загальні розв’язки наведено в поясненнях.

Гра «Обери формулу»

Обери формулу, яка безпосередньо використовує наведені дані. Вісім раундів.

Перевір себе: 10 запитань

Розв’язання з’являться після завершення тесту.

Домашнє завдання

Запиши загальний розв’язок. Потім знайди корені на [0°; 360°).

1. \(\sin x=-1\).

2. \(\cos x=\frac12\).

3. \(\tan x=-1\).

4. \(\cot x=0\).

5. \(\sin(2x)=0\).

6. \(\cos(x+60^\circ)=1\).

Розв’язання та відповіді

1. x = −90° + 360°k; на проміжку 270°.

2. x = ±60° + 360°k; 60° і 300°.

3. x = −45° + 180°k; 135° і 315°.

4. x = 90° + 180°k; 90° і 270°.

5. 2x = 180°k, x = 90°k; 0°, 90°, 180°, 270°.

6. x + 60° = 360°k, x = −60° + 360°k; 300°. Усюди k — ціле число.
