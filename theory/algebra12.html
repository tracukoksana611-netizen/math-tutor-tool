Ірраціональні рівняння

ОДЗ • квадратування • перевірка коренів • метод заміни

1. Корені та ОДЗ

Ірраціональне рівняння містить змінну під знаком кореня або в основі степеня з раціональним показником. Основні методи: піднесення до степеня, заміна змінної та спеціальні прийоми.

\[\sqrt{f(x)}\text{ визначений при }f(x)\ge0\]

Парний арифметичний корінь завжди невід’ємний. Непарний корінь визначений для всіх дійсних підкореневих значень. Для рівнянь із дробами також виключай нулі знаменників.

2. Два незалежні випадки

Непарний корінь

\[\sqrt[{2n+1}]{\,x\,}\;=\;a\qquad\Longleftrightarrow\qquad x=a^{2n+1},\quad a\in\mathbb R\]

Наприклад: \(\sqrt[3]{x}=-2\Rightarrow x=-8\).

Парний корінь

\[\sqrt[{2n}]{\,x\,}\;=\;a\qquad\Longleftrightarrow\qquad\begin{cases}x=a^{2n}\\a\ge0\end{cases}\]
a < 0 → розв’язків немає.
a = 0 → x = 0.
a > 0 → \(x=a^{2n}\).

n — натуральне число. Непарний і парний випадки не переходять один в одного.

3. Чому з’являються сторонні корені?

Квадратування стирає знак: 2 і −2 мають однакові квадрати. Тому з A = B випливає A² = B², але з рівності квадратів не завжди випливає A = B.

\[\sqrt{f(x)}=g(x)\iff\begin{cases}f(x)=g(x)^2\\g(x)\ge0\end{cases}\]

Невід’ємність f тут випливає з f = g². Якщо квадратуєш без умови g ≥ 0, знайдені числа — лише кандидати. Кожне потрібно підставити в початкове рівняння.

Приклад: \(\sqrt{x+5}=x-1\)

1. ОДЗ: x ≥ −5. Права частина невід’ємна, тому x ≥ 1.
2. \(x+5=(x-1)^2\Rightarrow x^2-3x-4=0\).
3. \((x-4)(x+1)=0\): кандидати 4 і −1.
4. x = 4: √9 = 3 — правильно. x = −1: √4 = −2 — неправильно.
\[x=4\]

4. Відокремлення квадратного кореня

\[\sqrt{x+2}+\sqrt{3-x}=3\]
1. ОДЗ: x + 2 ≥ 0 та 3 − x ≥ 0, отже −2 ≤ x ≤ 3.
2. Відокремимо один корінь: \(\sqrt{x+2}=3-\sqrt{3-x}\).
3. Квадратуємо та спрощуємо: \(x+2=12-x-6\sqrt{3-x}\), тому \(5-x=3\sqrt{3-x}\).
4. Ще раз квадратуємо: \((5-x)^2=9(3-x)\). Отримуємо \(x^2-x-2=0\).
5. \((x-2)(x+1)=0\): x = −1 або x = 2.
6. Перевіряємо початкове рівняння: при −1 маємо 1 + 2 = 3; при 2 маємо 2 + 1 = 3.
\[x\in\{-1;2\}\]

Обидва квадратування тут безпечні на ОДЗ: 3−√(3−x) > 0 та 5−x ≥ 2. Перевірка додатково підтверджує обидва корені.

5. Метод заміни

Якщо повторюється корінь, познач його новою змінною. Обов’язково запиши її допустимі значення.

\[\sqrt x+x=6,\quad t=\sqrt x\ge0,\quad x=t^2\]\[t^2+t-6=0\Rightarrow t=2\text{ або }t=-3\]

t = −3 відкидаємо: t — арифметичний корінь. Повертаємось: x = 2² = 4. Перевірка: 2 + 4 = 6.

Степінь з дробовим показником

\[x^{\frac14}-10=6\Rightarrow\sqrt[4]{x}=16\Rightarrow x=16^4=65536\]

6. Алгоритм і лайфхаки

1. Знайди ОДЗ та перевір знак правої частини.
2. Відокрем корінь або зроби заміну.
3. Піднеси до відповідного степеня та розв’яжи простіше рівняння.
4. Повернись до x, якщо була заміна.
5. Підстав кожного кандидата в початкове рівняння.

Лише належності ОДЗ недостатньо: −1 належить ОДЗ рівняння √(x+5) = x−1, але не є його коренем. Також пам’ятай: \(\sqrt{x^2}=|x|\).

Рівняння \(x+3=\sqrt{2x-1}\): чи має корені?

ОДЗ x ≥ 1/2. Після квадратування x² + 4x + 10 = 0. Дискримінант −24, тому дійсних коренів немає.

Лабораторія парних і непарних коренів

Порівняй показники 2 і 3 при a = −2. Потім спробуй a = 0. Чому відповіді різні?

Тренажер: 18 завдань за рівнями

У задачах про ОДЗ введи заборонені значення; у рівняннях — усі корені. Числа відділяй крапкою з комою: −2; 0. Дроби: 1/2, корені: (3+sqrt(5))/2. Якщо коренів немає, напиши немає.

Порядок чисел не важливий. Десяткові відповіді округлюй щонайменше до трьох знаків після коми.

Гра «Корінь чи сторонній кандидат?»

Чи можна підставити кандидата у початковий дріб? Вісім раундів.

Перевір себе: 10 завдань

У задачах про ОДЗ вводь заборонені значення; у решті — всі корені через крапку з комою. Якщо коренів немає — «немає». Розв’язання з’являться після завершення.

Домашнє завдання

1. Розв’яжи \(\sqrt{x-2}=4\).

Розв’язання

ОДЗ x≥2. x−2=16 ⇒ x=18. √16=4.

2. Розв’яжи \(\sqrt[3]{x}=-2\).

Розв’язання

Непарний корінь допускає від’ємне значення. x=(−2)³=−8.

3. Розв’яжи \(\sqrt{2x-1}=x-1\).

Розв’язання

Права частина невід’ємна: x≥1. Квадратування: 2x−1=(x−1)² ⇒ x²−4x+2=0 ⇒ x=2±√2. Корінь 2−√2<1 відкидаємо. Відповідь 2+√2.

4. Розв’яжи \(\sqrt{3x+1}=2\).

Розв’язання

3x+1=4 ⇒ x=1. Перевірка √4=2.

5. Розв’яжи \(\sqrt{x^2}=3\).

Розв’язання

√(x²)=|x|. |x|=3 ⇒ x=±3.

6. Розв’яжи \(\sqrt{x}+x=6\).

Розв’язання

t=√x≥0, x=t². t²+t−6=(t+3)(t−2)=0. t=−3 відкидаємо, t=2 ⇒ x=4. Перевірка: 2+4=6.
