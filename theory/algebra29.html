1. Хто тут невідомий, а хто параметр?

x — шукане невідоме, a — параметр. Параметр можна уявити ручкою налаштування: змінюємо a — отримуємо інше рівняння.

ax = 6: при a = 2 отримуємо x = 3; при a = −3 — x = −2; при a = 0 маємо 0x = 6, розв’язків немає.

Задача може просити всі корені залежно від a або лише значення a, за яких корені мають потрібну властивість.

Головне запитання: за яких значень параметра змінюється спосіб розв’язання?

2. Лінійне рівняння: три двері

\[A(a)x=B(a)\]
A(a) ≠ 0 → єдиний корінь \(x=\frac{B(a)}{A(a)}\).
A(a) = 0, B(a) ≠ 0 → коренів немає.
A(a) = 0, B(a) = 0 → усі допустимі x.

Не діли на вираз із параметром, доки не розглянеш випадок, коли він дорівнює нулю.

Приклад: (a − 2)x = a² − 4

При a ≠ 2: \(x=\frac{(a-2)(a+2)}{a-2}=a+2\). При a = 2: 0x = 0, тому будь-яке дійсне x. Скорочення без перевірки втратило б цей випадок.

3. Алгоритм дослідника

1. Запиши ОДЗ для x та обмеження на параметр.
2. Знайди особливі значення a: нуль знаменника, нуль старшого коефіцієнта, збіг коренів.
3. Для загального випадку розв’яжи рівняння.
4. Перевір корені в ОДЗ та застосуй додаткову умову.
5. Об’єднай усі випадки. Якщо потрібні цілі a, випиши їх окремо.

Піднесення до квадрата може додати сторонні корені; ділення на вираз може втратити корені. Перевірка в початковому рівнянні завершує роботу.

4. Додатний корінь: приклад 1

Знайди найбільше ціле a, за якого корінь рівняння додатний:

\[3x-4a=\frac{2ax+3}{5}\]
Множимо на 5: 15x − 20a = 2ax + 3.
Групуємо: (15 − 2a)x = 20a + 3.
При \(a=\frac{15}2\) отримуємо 0x = 153, коренів немає.
При \(a\ne\frac{15}2\): \(x=\frac{20a+3}{15-2a}\).

Дріб додатний, коли чисельник і знаменник одного знака. Обидва додатні при \(-\frac3{20}<a<\frac{15}2\). Обидва від’ємні одночасно неможливі.

Отже a ∈ (−0,15; 7,5). Найбільше ціле a = 7. Перевір: x = 143 > 0.

5. Добуток, корінь і логарифм: приклад 2

Скільки цілих a ∈ [−11;11] дають два різні корені?

\[\sqrt{2x-a+4}\,(\log_2x-2)=0\]

Спільна ОДЗ: x > 0 та 2x − a + 4 ≥ 0. Навіть коли один множник нуль, інший повинен бути визначений.

Перший множник нуль: \(x_1=\frac{a-4}2\). Для x₁ > 0 потрібно a > 4.
Другий множник нуль: x₂ = 4. Підкореневий вираз 12 − a ≥ 0, тому a ≤ 12.
Різні корені: \(\frac{a-4}2\ne4\), тобто a ≠ 12.

Два різні корені існують при 4 < a < 12. Перетин із [−11;11] дає (4;11].

Цілі значення: 5, 6, 7, 8, 9, 10, 11 — 7 значень.
Чому a = 4 і a = 12 не підходять?

При a = 4 кандидат x₁ = 0 порушує ОДЗ логарифма. При a = 12 обидва кандидати дорівнюють 4 — це один корінь, а не два.

6. Показникова заміна: приклад 3

Знайди найменше ціле a, за якого рівняння має два різні корені x різних знаків:

\[(2a-1)25^x-(4a+8)5^x+20=0\]
Нехай t = 5ˣ. Тоді t > 0, 25ˣ = t².
\[(2a-1)t^2-(4a+8)t+20=(t-2)((2a-1)t-10)=0\]

При a = 1/2 рівняння лінійне, має тільки t = 2. При a ≠ 1/2 кандидати \(t_1=2\), \(t_2=\frac{10}{2a-1}\). Другий додатний лише при a > 1/2.

x₁ = log₅2 > 0. Щоб x₂ був від’ємним, потрібно 0 < t₂ < 1.
\[0<\frac{10}{2a-1}<1\quad\Longrightarrow\quad a>\frac{11}2\]
Найменше ціле a = 6. Тоді t₂ = 10/11, тому x₂ < 0.

Якщо користуєшся дискримінантом: \(D=(4a-12)^2\), тому \(\sqrt D=|4a-12|\). Факторизація тут простіша й не потребує розкриття модуля.

7. Квадратне рівняння: кількість коренів

Для \(A(a)x^2+B(a)x+C(a)=0\) спочатку перевір A(a) = 0. Лише при A ≠ 0 застосовуй \(D=B^2-4AC\).

D > 0 — два різні дійсні корені; D = 0 — один; D < 0 — немає дійсних коренів.

Вієт: \(x_1+x_2=-\frac BA\), \(x_1x_2=\frac CA\).

При A ≠ 0 різні знаки коренів еквівалентні C/A < 0: дискримінант тоді автоматично додатний.

Для двох різних додатних коренів потрібні D > 0, сума > 0, добуток > 0. Для двох різних від’ємних — D > 0, сума < 0, добуток > 0.

Після t = 5ˣ знак x визначає не знак t, а його положення відносно 1: t > 1 → x > 0; 0 < t < 1 → x < 0.

8. Лайфхаки та пастки

🚦 Виділяй особливі значення a перед діленням.

🎯 Перекладай вимогу на формулу: «додатний корінь» → x > 0; «два різні» → x₁ ≠ x₂.

🧩 Для добутку спочатку спільна ОДЗ, потім кожен множник окремо.

🔢 Для цілих значень на проміжку випиши крайні допустимі цілі та порахуй включно.

Знайди помилку: √(a − 2)² = a − 2 для всіх a

Правильно |a − 2|. При a = 0 ліва частина 2, а a − 2 = −2.

Знайди помилку: (a − 1)x = 0 завжди має тільки x = 0

При a ≠ 1 так. При a = 1 рівність 0 = 0 виконується для будь-якого дійсного x.

Лабораторія: скільки коренів?

Досліджуємо x² − 2ax + 1 = 0. Корені — перетини параболи з OX.

При |a| < 1 коренів немає; при |a| = 1 один; при |a| > 1 два. За a > 1 обидва додатні, за a < −1 обидва від’ємні.

Перевір себе: 10 запитань

Розв’язання з’являться після завершення тесту.

Домашня експедиція

1. Досліди ax = a − 1 залежно від a.

2. Досліди (a − 3)x = a² − 9.

3. Знайди всі a, за яких x² − 6x + a = 0 має два різні додатні корені.

4. Скільки цілих a ∈ [−5;5] дають додатний корінь x = (a − 1)/(a + 2)?

5. Для рівняння \(\sqrt{2x-a+4}(\log_2x-2)=0\) перевір a = 4, 8, 12, 14.

6. За якого a рівняння \((2a-1)25^x-(4a+8)5^x+20=0\) має корінь x = 0?

Розв’язання

1. a ≠ 0: \(x=\frac{a-1}a\); a = 0: коренів немає.

2. a ≠ 3: x = a + 3; a = 3: усі дійсні x.

3. D = 36 − 4a > 0, сума 6 > 0, добуток a > 0 → 0 < a < 9.

4. a < −2 або a > 1: −5, −4, −3, 2, 3, 4, 5. Сім значень.

5. a = 4: {4}; a = 8: {2;4}; a = 12: {4}; a = 14: {5}. При a = 14 кандидат x = 4 порушує ОДЗ кореня.

6. x = 0 → t = 1; 2a − 1 − 4a − 8 + 20 = 0 → a = 11/2.
