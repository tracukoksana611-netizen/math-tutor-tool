Похідна: швидкість зміни та дотична

📈 Зміна функції🧮 Правило🚗 Швидкість📐 Дотична

1. Від середньої зміни до миттєвої

Для двох точок графіка середня швидкість зміни — відношення приростів:

\[\frac{\Delta y}{\Delta x}=\frac{f(x_0+h)-f(x_0)}h\]

Якщо друга точка наближається до першої, січна наближається до дотичної. Похідна — границя цього відношення, якщо вона існує як скінченне число:

\[f'(x_0)=\lim_{h\to0}\frac{f(x_0+h)-f(x_0)}h\]
f(x) = x²: \(\frac{(x+h)^2-x^2}h=2x+h\), h ≠ 0.
При h → 0 отримуємо f′(x) = 2x. При x = 3 нахил 6.
Не підставляй h = 0 у початковий дріб: це 0/0. Спочатку перетвори вираз, потім знайди границю.

2. Де похідна існує?

Якщо функція має похідну в точці, вона диференційовна й неперервна в цій точці. Зворотне твердження неправильне.

Наприклад, |x| неперервна в 0, але лівий нахил −1, правий +1. Є злам, похідної немає.

У точці розриву скінченної похідної немає. Вертикальна дотична також не означає скінченну похідну: √x у 0 не має скінченної правої похідної.

Формули застосовуй лише там, де функція та відповідна похідна визначені.

3. Степені, дроби та корені

\[(C)'=0,\quad(x)'=1,\quad(x^n)'=nx^{n-1}\]\[\left(\frac1x\right)'=-\frac1{x^2}\]\[(\sqrt x)'=\frac1{2\sqrt x}\]\[(\sqrt[n]x)'=\frac1{n(\sqrt[n]x)^{n-1}}\quad(n\ge2)\]

Степінь переносимо множником і зменшуємо на 1. Для загального дійсного степеня безпечно працювати на x > 0; для цілих степенів враховуємо їхню область визначення.

Для 1/x виключаємо x = 0; для √x формула похідної діє при x > 0. Для непарного кореня n ≥ 3 формула діє при x ≠ 0; для парного — при x > 0.

(x⁵)′ = 5x⁴; (x⁻²)′ = −2x⁻³.

4. Показникові, логарифмічні та тригонометричні

\[(e^x)'=e^x,\qquad(a^x)'=a^x\ln a\]\[(\ln x)'=\frac1x,\qquad(\log_a x)'=\frac1{x\ln a}\]\[(\sin x)'=\cos x,\qquad(\cos x)'=-\sin x\]\[(\tan x)'=\frac1{\cos^2x},\qquad(\cot x)'=-\frac1{\sin^2x}\]

Для показникової a > 0. Для logₐx: a > 0, a ≠ 1, x > 0; для ln x: x > 0. Для tan x виключаємо cos x = 0; для cot x — sin x = 0.

Тригонометричні формули використовують радіани. Похідна ln|x| також 1/x на кожному проміжку, де x ≠ 0.

5. Множник і сума: приклади зі сторінки

\[(Cf)'=Cf',\qquad(f\pm g)'=f'\pm g'\]
\((5x^7)'=5\cdot7x^6=35x^6\).
\[(3x^3+5x^2-8\sqrt x+6)'=9x^2+10x-\frac4{\sqrt x}\quad(x>0)\]

Стала 6 зникає. Множник −8 залишається біля похідної кореня.

6. Добуток та частка

\[(fg)'=f'g+fg'\]\[\left(\frac fg\right)'=\frac{f'g-fg'}{g^2}\quad(g\ne0)\]

Похідна добутку — сума двох добутків. У частці порядок у чисельнику важливий.

\((x^2(2x+5))'=2x(2x+5)+2x^2=6x^2+10x\).
\[\left(\frac{2x^3}{5x+6}\right)'=\frac{6x^2(5x+6)-10x^3}{(5x+6)^2}=\frac{20x^3+36x^2}{(5x+6)^2}\]

Тут x ≠ −6/5. Можна перевірити чисельник розкриттям дужок.

Помилка: (fg)′ = f′g′. Для x · x ця помилка дала б 1, але правильна похідна x² — 2x.

7. Складена функція: зовнішня й внутрішня

\[(f(g(x)))'=f'(g(x))\cdot g'(x)\]

Зовнішня похідна обчислюється в g(x), а не просто в x. Потім множимо на похідну внутрішньої функції.

\(y=(\frac13x+4)^3\): зовнішня — куб, внутрішня — x/3 + 4.
\[y'=3\left(\frac x3+4\right)^2\cdot\frac13=\left(\frac x3+4\right)^2\]

Для sin(2x): похідна 2cos(2x). Для e^(3x): 3e^(3x). Для ln(5x + 1): 5/(5x + 1), x > −1/5.

8. Механічний зміст: координата → швидкість → прискорення

\[v(t)=s'(t),\qquad a(t)=v'(t)=s''(t)\]

s(t) — координата, v — швидкість зі знаком, a — прискорення. Якщо s у метрах, t у секундах, v вимірюємо м/с, a — м/с².

s(t) = t³ − 3t: v(t) = 3t² − 3, a(t) = 6t.

При t = 2: v = 9 м/с, a = 12 м/с². Від’ємна v означає рух у від’ємному напрямі осі; модуль швидкості дорівнює |v|.

Середня швидкість зміни координати на [t₁;t₂] — (s(t₂) − s(t₁))/(t₂ − t₁). Це не завжди миттєва швидкість.

9. Геометричний зміст і дотична

\[k=f'(x_0)=\tan\alpha\]\[y=f'(x_0)(x-x_0)+f(x_0)\]

k — нахил дотичної; α — кут із додатним напрямом OX за однакового масштабу осей. k > 0 — дотична піднімається, k < 0 — опускається, k = 0 — горизонтальна.

Приклад зі сторінки: f(x) = 2x² + 5x − 3, x₀ = 1.

1. f(1) = 2 + 5 − 3 = 4: точка (1;4).
2. f′(x) = 4x + 5; f′(1) = 9.
3. y = 9(x − 1) + 4 = 9x − 5.
Перевір: при x = 1 дотична має y = 4 і нахил 9. Число f′(1) = 9 — не ордината точки!

Лабораторія рухомої дотичної

Парабола f(x) = x². Рухай точку x₀ та спостерігай за нахилом.

Фіолетова — графік, зелена — дотична, помаранчева — точка дотику. Крок сітки 1. При x₀ = 0 дотична горизонтальна.

Гра «Обери формулу»

Обери формулу, яка безпосередньо використовує наведені дані. Вісім раундів.

Перевір себе: 10 запитань

Розв’язання з’являться після завершення тесту.

Домашня практика

1. Знайди похідну x⁴ − 3x² + 7.

2. Знайди похідну (2x − 1)⁵.

3. Знайди похідну x² sin x.

4. Знайди похідну (x + 1)/(x − 1).

5. Дотична до y = x² + 1 при x₀ = 1.

6. s(t) = 2t² − 4t. Знайди v(3) та a(3).

Розв’язання

1. 4x³ − 6x.

2. 5(2x − 1)⁴ · 2 = 10(2x − 1)⁴.

3. 2x sin x + x² cos x.

4. \(\frac{(x-1)-(x+1)}{(x-1)^2}=-\frac2{(x-1)^2}\), x ≠ 1.

5. f(1) = 2, f′(1) = 2; y = 2(x − 1) + 2 = 2x.

6. v = 4t − 4 → 8; a = 4.
