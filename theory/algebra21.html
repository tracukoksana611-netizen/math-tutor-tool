1. Дві послідовності — два правила

Арифметична прогресія: до кожного члена додаємо те саме число d. Наприклад, 2, 5, 8, 11: d = 3.

Геометрична прогресія: кожен наступний член отримуємо множенням на q. Наприклад, 2, 6, 18, 54: q = 3.

Для арифметичної перевіряй різниці, для геометричної — відношення сусідніх членів. Один збіг ще не доводить правило для довільної послідовності.

Індекс n — номер члена, а не його значення. У формулах цього модуля n — додатне ціле число.

2. Арифметична прогресія: n-й член

\[d=a_{n+1}-a_n,\qquad a_n=a_1+(n-1)d\]

Від першого до n-го члена робимо n − 1 крок, тому множимо d на n − 1.

d > 0 — прогресія зростає; d < 0 — спадає; d = 0 — стала.

\[a_n=a_k+(n-k)d,\qquad d=\frac{a_j-a_i}{j-i}\quad(i\ne j)\]

Зручна властивість: кожен внутрішній член — середнє сусідніх: \(a_n=\frac{a_{n-1}+a_{n+1}}2\).

3. Приклад 1: знайди a₉

Дано a₄ = −5, a₅ = −7.

1. d = a₅ − a₄ = −7 − (−5) = −2.
2. a₁ = a₄ − 3d = −5 − 3 · (−2) = 1.
3. a₉ = a₁ + 8d = 1 + 8 · (−2) = −15.
Швидше: від a₄ до a₉ п’ять кроків. a₉ = −5 + 5 · (−2) = −15.

4. Сума арифметичної прогресії

\[S_n=\frac{a_1+a_n}{2}\,n=\frac{2a_1+(n-1)d}{2}\,n\]

Перше й останнє, друге й передостаннє мають однакову суму. Сума всіх членів — їхня кількість, помножена на середнє першого й останнього.

Приклад 2: a₁ = 3, d = −5. Знайди S₆.

a₆ = 3 + 5 · (−5) = −22.
\[S_6=\frac{3-22}{2}\cdot6=-57\]

Перевір списком: 3, −2, −7, −12, −17, −22. Сума −57.

5. Геометрична прогресія: n-й член

\[b_n=b_1q^{n-1},\qquad q=\frac{b_{n+1}}{b_n}\]

Для відношення потрібен bₙ ≠ 0. Тут основні приклади — прогресії з ненульовими членами, b₁ ≠ 0 і q ≠ 0.

q < 0 — знаки чергуються. При b₁ > 0 та q > 1 члени зростають; при b₁ > 0 та 0 < q < 1 спадають. Для від’ємного першого члена напрям інший.

При q = 1 прогресія стала. Якщо визначаємо послідовність рекурентно й дозволяємо q = 0, після першого члена всі наступні нулі; відношення 0/0 уже не визначене.

\[b_n^2=b_{n-1}b_{n+1}\]

Для додатних членів внутрішній член дорівнює геометричному середньому сусідніх. Для від’ємних не можна бездумно брати лише додатний корінь.

6. Приклад 3: знаменник і шостий член

Прогресія \(\frac1{81},\frac1{27},\frac19,\ldots\).

\[q=\frac{1/27}{1/81}=3\]

Ділення на дріб замінюємо множенням на обернений.

\[b_6=\frac1{81}\cdot3^5=3\]

Перевір: 1/81, 1/27, 1/9, 1/3, 1, 3. Від першого до шостого — п’ять множень.

7. Сума геометричної прогресії

\[S_n=b_1\frac{q^n-1}{q-1}\quad(q\ne1)\]

Рівноцінно \(S_n=b_1\frac{1-q^n}{1-q}\). Не змішуй чисельник однієї форми зі знаменником іншої.

При q = 1: Sₙ = nb₁. Формулу з діленням на q − 1 тоді використовувати не можна.

Приклад 4: b₁ = 2√2, b₇ = 16√2, q > 0. Знайди S₄.

q⁶ = b₇/b₁ = 8. Оскільки q > 0, q = √2.
Перші чотири члени: 2√2, 4, 4√2, 8.
\[S_4=12+6\sqrt2\]

Без умови q > 0 рівність q⁶ = 8 також дозволяла б q = −√2. Умова прибирає неоднозначність.

8. Нескінченна сума: тільки за потрібної умови

\[S=\frac{b_1}{1-q}\qquad(|q|<1)\]

Коли |q| < 1, члени й залишок суми прямують до нуля. Наприклад: 1 + 1/2 + 1/4 + … = 2.

При q = −1/2: 1 − 1/2 + 1/4 − … = 2/3. Знаки чергуються, але сума збігається.

Для ненульового b₁ та |q| ≥ 1 така нескінченна сума не збігається. Не підставляй q = 2 у формулу нескінченної суми.

9. Лайфхаки й типові помилки

📍 Для n-го члена — n − 1 крок. Для переходу від k-го до n-го — n − k.

➕ aₙ — один член, Sₙ — сума перших n членів.

🔎 Перевір відновлений перший член підстановкою у відомий aₖ або bₖ.

Учень: a₁ = 2, d = 3, тому a₅ = 2 + 5 · 3

Помилка в кількості кроків. a₅ = 2 + 4 · 3 = 14.

Учень: для 2, −6, 18 знаменник 3

Знаки чергуються: q = −6/2 = −3.

Учень: 1 + 2 + 4 + … = 1/(1 − 2) = −1

|q| = 2 ≥ 1: ряд не збігається. Формулу застосували поза її умовами.

Лабораторія послідовностей

Точки окремі: індекс n набуває лише цілих значень. Вертикальний масштаб автоматично змінюється. Сума — всіх показаних членів.

Перевір себе: 10 запитань

Розв’язання з’являться після завершення тесту.

Домашні сходинки

1. a₁ = 5, d = −2. Знайди a₁₀ та S₁₀.

2. a₄ = 11, a₉ = 26. Знайди d та a₁.

3. b₁ = 3, q = 2. Знайди b₆ та S₆.

4. b₁ = 8, q = 1/2. Знайди нескінченну суму.

5. b₁ = 2, q = −3. Знайди b₄.

6. a₁ = 2, d = 4. Який номер має член 42?

Відповіді та пояснення

1. a₁₀ = 5 − 18 = −13; S₁₀ = (5 − 13) · 10/2 = −40.

2. d = 15/5 = 3; a₁ = 11 − 3 · 3 = 2.

3. b₆ = 3 · 2⁵ = 96; S₆ = 3(64 − 1) = 189.

4. |q| < 1; S = 8/(1 − 1/2) = 16.

5. 2 · (−3)³ = −54.

6. 42 = 2 + 4(n − 1) → n = 11.
