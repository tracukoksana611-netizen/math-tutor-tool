Логарифмічні нерівності: ОДЗ + напрям знака

1. Два запитання перед розв’язуванням

Яка основа? При a > 1 логарифмічна функція зростає, при 0 < a < 1 — спадає.

Чи додатний аргумент? Для кожного логарифма його аргумент має бути строго більшим за нуль.

\[a>1:\quad \log_a f(x)>b\iff f(x)>a^b\]\[0<a<1:\quad\log_a f(x)>b\iff 0<f(x)<a^b\]
\[a>1:\quad\log_a f(x)<b\iff 0<f(x)<a^b\]\[0<a<1:\quad\log_a f(x)<b\iff f(x)>a^b\]

Для нестрогих знаків ≤ і ≥ змінюється лише відповідна межа порівняння. Умова f(x) > 0 завжди строга.

При a = 1 логарифм не визначений. Основа 0 чи від’ємна також не підходить.

2. Порівнюємо два логарифми

Якщо основи однакові та допустимі, порівнюй аргументи: при a > 1 зберігай знак, при 0 < a < 1 змінюй. Обидва аргументи повинні бути додатними.

\[\log_a f(x)>\log_a g(x)\iff\begin{cases}f(x)>g(x),&a>1,\\f(x)<g(x),&0<a<1,\end{cases}\]

До потрібної гілки додай ОДЗ: f(x) > 0, g(x) > 0. Умови поєднуємо перетином, а не об’єднанням.

3. Приклад 1: зростаюча функція

\(\log_8(2x-3)>\log_8 7\).
ОДЗ: 2x − 3 > 0, тобто \(x>\frac32\). Аргумент 7 додатний.
Основа 8 > 1: 2x − 3 > 7, звідси x > 5.
Перетин умов: x > 5. Відповідь: \((5;+\infty)\).

4. Приклад 2: спадаюча функція

\(\log_{\frac18}(2x-3)>\log_{\frac18}7\).
ОДЗ: \(x>\frac32\).
Основа між 0 і 1: 2x − 3 < 7, звідси x < 5.
Разом: \(\frac32<x<5\). Відповідь: \((\frac32;5)\).

5. Приклад 3: справа число

\(\log_2(5x+1)>4\). ОДЗ: \(x>-\frac15\).
Основа 2 > 1: \(5x+1>2^4=16\Rightarrow x>3\).
x > 3 автоматично забезпечує ОДЗ. Відповідь: \((3;+\infty)\).

6. Приклад 4: від’ємна права частина

\(\log_{\frac12}(5x-1)>-2\). ОДЗ: \(x>\frac15\).
Основа спадаюча: \(5x-1<(\frac12)^{-2}=4\Rightarrow x<1\).
Перетин: \(\frac15<x<1\). Відповідь: \((\frac15;1)\).

7. Приклад 5: сума логарифмів

\(\log_2 x+\log_2(x+4)<5\).
Початкова ОДЗ: x > 0 та x + 4 > 0. Разом x > 0.
На ОДЗ об’єднуємо: \(\log_2(x(x+4))<5\Rightarrow x(x+4)<32\).
\(x^2+4x-32<0\Rightarrow(x+8)(x-4)<0\Rightarrow-8<x<4\).
Перетинаємо з x > 0: \(x\in(0;4)\).
Умова x(x + 4) > 0 допускає також x < −4. Але там обидва початкові логарифми не визначені. Тому зберігай ОДЗ кожного аргументу!

8. Приклад 6: квадратна нерівність після заміни

\((\log_{\frac14}x)^2+2\log_{\frac14}x-8\le0\). ОДЗ: x > 0.
Позначаємо \(t=\log_{\frac14}x\). Значення t може бути будь-яким дійсним.
\(t^2+2t-8=(t+4)(t-2)\le0\Rightarrow-4\le t\le2\).
\(-4\le\log_{\frac14}x\le2\). Функція спадає: кожна гілка змінює напрям.
\(\log_{\frac14}x\ge-4\Rightarrow x\le(\frac14)^{-4}=256\).
\(\log_{\frac14}x\le2\Rightarrow x\ge(\frac14)^2=\frac1{16}\).
Відповідь: \(x\in[\frac1{16};256]\). Межі входять, бо знак нестрогий.

9. Пам’ятка і перевірка меж

1. Запиши ОДЗ усіх логарифмів.
2. Перевір основу й вибери напрям знака.
3. Розв’яжи отриману нерівність.
4. Перетни результат із початковою ОДЗ.
5. Підстав межі й одне число з кожного проміжку.

Нульовий аргумент ніколи не входить, навіть при знаку ≤ чи ≥. Біля нескінченності завжди кругла дужка.

Знайди помилку: \(\log_2 x\le0\Rightarrow x\le1\)

Забуто x > 0. Правильна відповідь: \((0;1]\).

Знайди помилку: після заміни t = logₐx вимагаємо t > 0

Додатним має бути x. Логарифм t може бути від’ємним: \(\log_2\frac12=-1\).

Лабораторія: зростання і спадання логарифма

Золота пунктирна лінія — рівень y = b. Подивись, де графік лежить вище лінії: це розв’язки logₐx > b. При основі 2 вони праворуч від aᵇ, при основі 1/2 — ліворуч, але завжди x > 0.

Обидва графіки проходять через (1; 0). Область визначення: x > 0. Логарифм може набувати від’ємних значень.
