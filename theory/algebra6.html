Степені та логарифми

Від «у який степінь?» до впевнених перетворень

1. Степінь і логарифм — дві сторони одного запитання

2³ = 8 ⇔ log28 = 3

Степінь: «Яке число отримаємо, якщо 2 помножити саме на себе тричі?» Логарифм: «У який степінь треба піднести 2, щоб отримати 8?»

Основа: 2
Число, яке підносимо до степеня.
Аргумент: 8
Число, яке хочемо отримати.

Відповідь логарифма — показник степеня: 3.

Для logₐb потрібно: a > 0, a ≠ 1, b > 0. Логарифм нуля чи від’ємного числа в дійсних числах не існує. Сам результат логарифма може бути від’ємним!

Наприклад: log₂(1/8) = −3, бо 2⁻³ = 1/8.

lg x — логарифм за основою 10. ln x — за основою e ≈ 2,71828.

2. Дев’ять правил степенів

Для довільних дійсних показників беремо додатні основи. Для цілих показників можливі й від’ємні основи, якщо всі вирази визначені.

1. Степінь суми

ax+y = ax · ay

При множенні степенів з однаковою основою показники додаємо.

Приклад і пояснення
3x+2 = 9 · 3x

2. Степінь різниці

ax−y = ax / ay

При діленні показники віднімаємо. Знаменник не дорівнює нулю.

Приклад і пояснення
25−x = 32 / 2x

3. Степінь степеня

axy = (ax)y

Показники перемножуємо.

Приклад і пояснення
72x = 49x

4. Добуток основ

ax · bx = (ab)x

Об’єднувати основи можна, коли показники однакові.

Приклад і пояснення
2x · 3x = 6x

5. Частка основ

ax / bx = (a/b)x

Однаковий показник залишається, основи ділимо.

Приклад і пояснення
3x / 5x = (3/5)x

6. Нульовий показник

a0 = 1

Основа не дорівнює нулю. Вираз 0⁰ тут не визначаємо.

Приклад і пояснення
70 = 1

7. Перший степінь

a1 = a

Перший степінь не змінює числа.

Приклад і пояснення
(1/7)1 = 1/7

8. Від’ємний показник

a−n = 1/an

Від’ємний показник означає обернене число, а не від’ємний результат. Основа ненульова.

Приклад і пояснення
2−3 = 1/8

9. Дробовий показник

am/n = ⁿ√(am)

Для цього модуля a > 0; m — ціле, n — натуральне. Знаменник показника — індекс кореня.

Приклад і пояснення
82/3 = (³√8)2 = 4

3. Десять логарифмічних тотожностей

У кожному правилі основа логарифма додатна й не дорівнює 1.

1. Основна тотожність

alogab = b

Логарифм показує, у який степінь треба піднести a. Тут a > 0, a ≠ 1, b > 0.

Приклад і пояснення
3log35 = 5

2. Логарифм одиниці

loga1 = 0

Будь-яка допустима основа в нульовому степені дає 1.

Приклад і пояснення
log131 = 0

3. Логарифм основи

logaa = 1

Перша степінь основи дорівнює самій основі.

Приклад і пояснення
log55 = 1

4. Логарифм добутку

loga(xy) = logax + logay

У звичайній формі x > 0, y > 0. Якщо xy > 0, але обидва множники від’ємні, використовуємо logₐ|x| + logₐ|y|.

Приклад і пояснення
log240 = 3 + log25

5. Логарифм частки

loga(x/y) = logax − logay

Для x > 0, y > 0. Якщо x/y > 0, можна записати різницю логарифмів модулів.

Приклад і пояснення
log3(3/17) = 1 − log317

6. Логарифм степеня

loga(xp) = p · logax

Для x > 0 і дійсного p. При x < 0 та цілому парному p: logₐ(xᵖ) = p logₐ|x|. Не переносимо це правило на довільний дійсний показник від’ємної основи.

Приклад і пояснення
log381 = 4

7. Степінь в основі

logaᵏx = (1/k) · logax

a > 0, a ≠ 1, k ≠ 0, x > 0. Показник основи переходить у знаменник.

Приклад і пояснення
log82 = 1/3

8. Степені в основі й аргументі

logaᵐ(an) = n/m

Запиши основу й аргумент як степені одного числа. m ≠ 0.

Приклад і пояснення
log432 = 5/2

9. Зміна основи

logab = logcb / logca

a > 0, a ≠ 1, b > 0, c > 0, c ≠ 1. Внизу — логарифм старої основи.

Приклад і пояснення
log253 = log53 / 2

10. Перестановка основ

alogcb = blogca

a > 0, b > 0, c > 0, c ≠ 1. У прикладі x > 0: перший доданок дорівнює xlog52. Додаємо 1 + 4 однакових вирази.

Приклад і пояснення
2log5x + 4xlog52 = 5xlog52

4. Логарифмування: добуток перетворюємо на суму

Нехай x = 7abc³; a > 0, a ≠ 1, b > 0, c > 0. Знайдемо logₐx.

1. Записуємо логарифм усього виразу: logₐx = logₐ(7abc³).
2. Добуток розкладаємо на суму: logₐ7 + logₐa + logₐb + logₐ(c³).
3. logₐa = 1; показник 3 виносимо вперед.
logax = loga7 + 1 + logab + 3logac

5. Потенціювання: повертаємося до числа

Дано: lg x = lg 7 + 2lg a − 3lg b, де a > 0, b > 0.

1. Повертаємо коефіцієнти в показники: lg 7 + lg(a²) − lg(b³).
2. Сума означає множення, різниця — ділення: lg(7a²/b³).
3. Рівні логарифми з однаковою основою мають рівні аргументи.
x = 7a²b³
Знайди помилку: log₂(8 + 4) не дорівнює log₂8 + log₂4. Правило розкладання працює для добутку, а не для суми. Також log₂(−4) не існує, хоча log₂((-4)²) існує.

Лабораторія: степінь і логарифм

Синій: y = aˣ. Помаранчевий: y = logₐx. Пунктир: y = x. Графіки симетричні відносно цієї прямої.

Коли a > 1, обидві функції зростають. Коли 0 < a < 1 — спадають. Логарифм визначений тільки при x > 0.

Тренажер

Вводь число, десятковий дріб із комою або крапкою, чи звичайний дріб: 1/3. Відповіді зберігаються лише в цьому браузері, якщо він дозволяє збереження.

Гра «Знайди показник»

Вибери правильне значення логарифма. Спробуй пройти 8 раундів.

Перевір себе: 10 запитань

Розв’язання з’являться після завершення тесту.

Домашнє завдання

A — закріплення

1. Обчисли: 5⁰; 3⁻²; log₂16; log₅25.

2. Поясни словами, чому log₇1 = 0.

B — перетворення

3. Обчисли: log₄64; log₂48 − log₂3; 27^(2/3).

4. Розклади log₃(9x²/y), де x > 0, y > 0.

C — застосування

5. Знайди x: lg x = lg 5 + 2lg 3 − lg 9.

6. Чи правильне log₂(x²) = 2log₂x при x = −2? Запиши правильну рівність.

Відповіді та пояснення

1. 1; 1/9; 4; 2.

2. Бо 7⁰ = 1.

3. 3; 4; 9.

4. 2 + 2log₃x − log₃y.

5. x = 5 · 9 / 9 = 5.

6. Ні: log₂(−2) не існує. Правильно: log₂(x²) = 2log₂|x| при x ≠ 0. Для x = −2 результат 2.
