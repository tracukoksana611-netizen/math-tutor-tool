Логарифмічні рівняння: спочатку ОДЗ

1. Логарифм відповідає на запитання «який показник?»

Запис \(\log_a x=b\) означає: до якого степеня потрібно піднести a, щоб отримати x? Відповідь — b.

\[\log_a x=b\iff x=a^b\qquad(a>0,\ a\ne1,\ x>0)\]

Наприклад, \(\log_2 8=3\), бо \(2^3=8\); \(\log_2\frac18=-3\), бо \(2^{-3}=\frac18\).

Основа додатна й не дорівнює 1. Аргумент — вираз під логарифмом — строго додатний. Логарифм нуля або від’ємного числа в дійсних числах не визначений.

2. Три основні способи

\[\log_a f(x)=b\iff f(x)=a^b\]\[\log_a f(x)=\log_a g(x)\iff\begin{cases}f(x)=g(x),\\f(x)>0,\\g(x)>0.\end{cases}\]

У другому правилі після рівності f = g достатньо перевірити додатність одного з рівних виразів. Але початкову ОДЗ зручно записувати для обох логарифмів.

Для кількох логарифмів: спільна основа → правила суми й різниці → за потреби заміна.

\[\log_a u+\log_a v=\log_a(uv)\]\[\log_a u-\log_a v=\log_a\frac uv\qquad(u>0,\ v>0)\]\[\log_{a^k}x=\frac1k\log_a x\qquad(k\ne0)\]

Додатність добутку uv не замінює дві початкові умови u > 0 та v > 0.

3. Приклад 1: найпростіше рівняння

\(\log_2 x=8\). ОДЗ: x > 0.
За означенням: \(x=2^8=256\).
256 > 0, тому корінь допустимий. Перевірка: \(\log_2 256=8\).

4. Приклад 2: аргумент — вираз

\(\log_2(x+5)=6\). ОДЗ: x + 5 > 0, тобто x > −5.
\(x+5=2^6=64\Rightarrow x=59\).
59 > −5. Перевірка: \(\log_2(59+5)=\log_2 64=6\).

5. Приклад 3: рівні логарифми

\(\log_7(x+1)=\log_7(4x-5)\).
ОДЗ: x + 1 > 0 і 4x − 5 > 0. Разом \(x>\frac54\).
Прирівнюємо аргументи: x + 1 = 4x − 5.
3x = 6, отже x = 2.
2 належить ОДЗ. Обидва аргументи дорівнюють 3.

6. Приклад 4: три основи зводимо до 3

\(2\log_3 x+\log_9 x-\log_{27}x=6{,}5\). ОДЗ: x > 0.
\(9=3^2,\ 27=3^3\), тому \(\log_9 x=\frac12\log_3 x\), \(\log_{27}x=\frac13\log_3 x\).
\((2+\frac12-\frac13)\log_3 x=\frac{13}2\).
\(\frac{13}6\log_3 x=\frac{13}2\Rightarrow\log_3 x=3\).
\(x=3^3=27\). Перевірка: \(2\cdot3+\frac32-1=6{,}5\).

7. Приклад 5: сума логарифмів і два корені

\(\log_{0{,}5}(4-x)+\log_{0{,}5}(x-1)=-1\).
ОДЗ: 4 − x > 0 і x − 1 > 0, тобто 1 < x < 4.
\(\log_{0{,}5}((4-x)(x-1))=-1\).
\((4-x)(x-1)=(\frac12)^{-1}=2\).
\(-x^2+5x-4=2\Rightarrow x^2-5x+6=0\).
\((x-2)(x-3)=0\Rightarrow x=2\) або x = 3.
Обидва корені належать ОДЗ. Для кожного добуток аргументів 2, а \(\log_{0{,}5}2=-1\). Відповідь: 2; 3.

8. Приклад 6: квадрат логарифма

\((\log_2 x)^2+3\log_2 x-4=0\). ОДЗ: x > 0.
Позначаємо \(t=\log_2 x\). Тут t може бути будь-яким дійсним числом!
\(t^2+3t-4=0\Rightarrow(t+4)(t-1)=0\).
t = −4 або t = 1. Обидва значення допустимі.
\(\log_2 x=-4\Rightarrow x=2^{-4}=\frac1{16}\).
\(\log_2 x=1\Rightarrow x=2\). Обидва x додатні.
Перевірка: для t = −4 маємо 16 − 12 − 4 = 0; для t = 1 маємо 1 + 3 − 4 = 0.
Не плутай заміни: при t = aˣ потрібно t > 0; при t = logₐx обмеження t > 0 немає.

9. Алгоритм і лайфхаки

1. Запиши умови для основ і всіх аргументів.
2. Обери перехід до степеня, рівність аргументів, зміну основи або заміну.
3. Знайди всі кандидати.
4. Повернися до x, перевір ОДЗ і початкову рівність.

Якщо \(\log_a f(x)=b\), то \(f(x)=a^b>0\) автоматично забезпечує додатність цього аргументу. Проте ОДЗ інших виразів усе одно потрібно перевірити.

Знайди помилку: «логарифм від’ємний — корінь відкидаємо»

Від’ємним може бути значення логарифма, але не його аргумент. Наприклад, \(\log_2\frac14=-2\) — правильний запис.

Знайди помилку: \(\log_2(x-2)+\log_2(x-3)=1\)

Після об’єднання: (x − 2)(x − 3) = 2, звідки x = 1 або 4. ОДЗ x > 3. Тому відповідь лише 4: при x = 1 обидва аргументи від’ємні.

Лабораторія: логарифм і степінь

Задай значення b. Горизонтальна лінія перетинає графік у точці з координатою x = aᵇ. Якщо b від’ємне, аргумент x усе одно додатний.

Обидва графіки проходять через (1; 0). Функція з основою 2 зростає, з основою 1/2 — спадає. При x ≤ 0 графіка немає.
