Раціональні рівняння

ОДЗ • спільний знаменник • перевірка коренів • метод заміни

1. Що таке раціональне рівняння?

Це рівняння, обидві частини якого — раціональні вирази: многочлени або їхні частки. Якщо у знаменнику є змінна, рівняння називаємо дробовим раціональним.

\[\frac{x+1}{5x-7}=\frac3{4-x}\]

Головна відмінність від цілих рівнянь: деякі значення x заборонені, бо знаменник не може дорівнювати нулю.

Перед перетвореннями завжди запиши ОДЗ — область допустимих значень змінної.

2. ОДЗ: знаменник не дорівнює нулю

Перевіряємо всі знаменники початкового рівняння. Чисельник може дорівнювати нулю — знаменник не може.

\[\frac1x:\quad x\ne0\]
\[\frac1{x-3}:\quad x\ne3\]
\[\frac1{x(x+2)}:\quad x\ne0,\quad x\ne-2\]

Для першого прикладу

\[5x-7\ne0,\quad4-x\ne0\quad\Rightarrow\quad x\ne\frac75,\quad x\ne4\]

Ці обмеження зберігаємо до кінця, навіть якщо відповідний множник потім скоротиться.

ОДЗ — ще не відповідь. Вона лише показує, які числа взагалі можна підставляти. Серед дозволених чисел треба знайти ті, що задовольняють рівність.

3. Коли дріб дорівнює нулю?

\[\frac{P(x)}{Q(x)}=0\quad\Longleftrightarrow\quad\begin{cases}P(x)=0,\\Q(x)\ne0.\end{cases}\]

Одночасно виконуються дві умови: чисельник — нуль, знаменник — не нуль.

Приклад: \(\frac{x^2-9}{x-3}=0\)

1. ОДЗ: x ≠ 3.
2. Розв’язуємо \(x^2-9=0\): кандидати x = −3 та x = 3.
3. x = 3 відкидаємо: знаменник стає нулем. x = −3 допустимий.
\[\text{Відповідь: }x=-3\]
Чому після скорочення не можна повернути x = 3?
\[\frac{(x-3)(x+3)}{x-3}=x+3\quad\text{лише при }x\ne3\]

Початковий дріб при x = 3 не існує. Скорочення змінює запис, але не скасовує початкову ОДЗ.

4. Спільний знаменник: покроковий алгоритм

1. Знайди ОДЗ початкового рівняння.
2. Перенеси всі дроби в одну частину й зведи до спільного знаменника або помнож обидві частини на нього.
3. Розв’яжи отримане ціле рівняння.
4. Перевір кожного кандидата за ОДЗ та підстановкою в початкове рівняння.

Розв’яжемо \(\frac{3x}{x+2}=\frac1x\)

1. ОДЗ: x ≠ −2, x ≠ 0.
2. Спільний знаменник — \(x(x+2)\). На ОДЗ він ненульовий.
\[\frac{3x}{x+2}-\frac1x=0\quad\Rightarrow\quad\frac{3x^2-(x+2)}{x(x+2)}=0\]
3. Прирівнюємо чисельник до нуля. Мінус перед дужками змінює обидва знаки!
\[3x^2-x-2=0\quad\Rightarrow\quad(3x+2)(x-1)=0\]
\[x_1=1,\qquad x_2=-\frac23\]
4. Обидва числа належать ОДЗ.

Перевірка x = 1: обидві частини дорівнюють 1. Для \(x=-\frac23\) обидві частини дорівнюють \(-\frac32\).

\[\text{Відповідь: }1;\ -\frac23\]
У рівнянні можна множити на від’ємний ненульовий спільний знаменник: знак рівності не змінюється. Правило зміни знака порівняння стосується нерівностей.

5. Сторонній кандидат: чому потрібна перевірка

Розв’яжемо \(\frac{x^2-4}{x-2}=4\)

1. ОДЗ: x ≠ 2.
2. Скорочуємо на ОДЗ:
\[\frac{(x-2)(x+2)}{x-2}=4\Rightarrow x+2=4\Rightarrow x=2\]
3. Кандидат x = 2 заборонений. Отже, початкове рівняння не має коренів.
\[\text{Відповідь: }\varnothing\]

У лабораторії видно графік із «діркою»: формула після скорочення задає пряму, але початковий дріб не має точки при забороненому значенні.

6. Метод заміни: \(x+\frac{1}{x}\)

Заміна спрощує рівняння, якщо один і той самий вираз повторюється. Але після знаходження нової змінної потрібно повернутися до x.

Розв’яжемо

\[7\left(x+\frac1x\right)-2\left(x^2+\frac1{x^2}\right)=9\]
1. ОДЗ: x ≠ 0. Позначимо \(t=x+\frac1x\).
2. Підносимо вираз до квадрата. Добуток \(x\cdot\frac1x=1\).
\[t^2=\left(x+\frac1x\right)^2=x^2+2+\frac1{x^2}\]
\[x^2+\frac1{x^2}=t^2-2\]
3. Отримуємо квадратне рівняння для t:
\[7t-2(t^2-2)=9\Rightarrow2t^2-7t+5=0\]
\[(2t-5)(t-1)=0\Rightarrow t=\frac52\ \text{або}\ t=1\]
4. Повертаємося до x для кожного t.
\[x+\frac1x=\frac52\Rightarrow2x^2-5x+2=0\Rightarrow x=2\ \text{або}\ x=\frac12\]
\[x+\frac1x=1\Rightarrow x^2-x+1=0\]

Для другого рівняння D = −3, тому дійсних коренів немає.

5. Числа 2 та \(\frac12\) допустимі. Для обох \(x+\frac1x=\frac52\), \(x^2+\frac1{x^2}=\frac{17}{4}\), тому початкова ліва частина дорівнює 9.
\[\text{Відповідь: }\frac12;\ 2\]

7. Лайфхаки та пастки

Дріб дорівнює нулю → нуль у чисельнику, ненульовий знаменник.
Скорочувати можна множники, а не окремі доданки.
Після множення на спільний знаменник не забудь ОДЗ.
Нуль у знаменнику — заборона, а не «ще один корінь».
У \(x+\frac1x=t\) значення t і x — різні речі. Завжди виконуй зворотну заміну.

Швидка перевірка допустимих t

Із \(x+\frac1x=t\) отримуємо \(x^2-tx+1=0\). Його дискримінант \(t^2-4\). Дійсні x можливі лише при \(|t|\ge2\). Тому t = 1 у попередньому прикладі відразу можна відкинути.

Знайди помилку учня

Учень розв’язав \(\frac{x^2-1}{x-1}=0\) і записав x = −1; 1.

Пояснення

x = 1 не належить ОДЗ. Відповідь лише −1. Рівність \(\frac00=0\) не має змісту: на нуль ділити не можна.

Лабораторія: скорочення не скасовує ОДЗ

Досліджуємо рівняння \(\frac{x^2-k^2}{x-k}=0\). Змінюй k і спостерігай, який кандидат залишається.

Порожнє помаранчеве коло — відсутня точка графіка. Зелена точка — допустимий корінь. При k = 0 навіть точка перетину осі x виключена.

Досліди

1. Встанови k = 3. Чому корінь −3 підходить, а 3 — ні?

2. Встанови k = 0. Чому рівняння тепер не має коренів?

3. Поясни, чому графік збігається з прямою лише на ОДЗ.

Тренажер: 24 завдання за рівнями

У задачах про ОДЗ введи заборонені значення; у рівняннях — усі корені. Числа відділяй крапкою з комою: −2; 0. Дроби: 1/2, корені: (3+sqrt(5))/2. Якщо коренів немає, напиши немає.

Порядок чисел не важливий. Десяткові відповіді округлюй щонайменше до трьох знаків після коми.

Гра «Пропусти корінь через ОДЗ»

Чи можна підставити кандидата у початковий дріб? Вісім раундів.

Перевір себе: 10 завдань

У задачах про ОДЗ вводь заборонені значення; у решті — всі корені через крапку з комою. Якщо коренів немає — «немає». Розв’язання з’являться після завершення.

Домашнє завдання

A — ОДЗ і прості рівняння

1. Знайди заборонені значення для \(\frac1{x(x-4)}\).

2. Розв’яжи \(\frac2x=1\).

3. Розв’яжи \(\frac{x-5}{x+2}=0\).

B — перетворення

4. \(\frac{x^2-16}{x-4}=0\).

5. \(\frac1{x-1}=\frac2x\).

6. \(\frac{x^2-4}{x-2}=4\).

C — заміна

7. \(x+\frac1x=\frac52\).

8. \(x+\frac1x=0\).

9. Поясни, чому в рівнянні \(\frac{x-3}{x-3}=0\) немає коренів.

Відповіді з розв’язаннями

1. x ≠ 0 та x ≠ 4; заборонені значення 0 і 4.

2. x ≠ 0. \(2=x\). Корінь 2.

3. x ≠ −2. Нуль чисельника x = 5 допустимий.

4. x ≠ 4. Кандидати −4 та 4, залишаємо лише −4.

5. x ≠ 0; 1. \(x=2(x-1)\Rightarrow x=2\).

6. x ≠ 2. Після скорочення x = 2, але він заборонений. Коренів немає.

7. x ≠ 0. \(2x^2-5x+2=0\), корені \(\frac12\) і 2.

8. \(x^2+1=0\) не має дійсних коренів.

9. При x ≠ 3 дріб дорівнює 1, а при x = 3 він не визначений. Жодне число не дає нуль.
