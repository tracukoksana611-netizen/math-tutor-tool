Раціональні нерівності

ОДЗ • знаки дробу • метод інтервалів • заборонені точки

1. Що таке раціональна нерівність?

Це нерівність із дробом, у якому чисельник P(x) і знаменник Q(x) — многочлени.

\[\frac{P(x)}{Q(x)}\gtrless0,\qquad Q(x)\ne0\]

Спочатку ОДЗ: знайди значення, за яких знаменник дорівнює нулю, та виключи їх. Навіть знак ≥ або ≤ не дозволяє ділити на нуль.

Чому не можна просто «прибрати знаменник»?

Його знак залежить від x. При множенні на від’ємний знаменник знак нерівності треба змінити. Безпечний спосіб — метод інтервалів або множення на квадрат знаменника.

\[\frac{P}{Q}=\frac{PQ}{Q^2},\quad Q^2>0\text{ на ОДЗ}\]

Тому знак дробу збігається зі знаком добутку PQ, але всі заборонені точки залишаються виключеними.

2. Усі чотири правила

\[\frac P Q>0\iff PQ>0\]\[\frac P Q<0\iff PQ<0\]\[\frac P Q\ge0\iff\begin{cases}PQ\ge0\\Q\ne0\end{cases}\]\[\frac P Q\le0\iff\begin{cases}PQ\le0\\Q\ne0\end{cases}\]

Для строгого знака умова PQ > 0 або PQ < 0 вже виключає Q = 0. Для нестрогого знака ОДЗ потрібно записати окремо.

3. Метод інтервалів — покроково

1. Перенеси все вліво, справа залиш 0. Зведи до спільного знаменника.
2. Запиши ОДЗ та розклади чисельник і знаменник на множники.
3. Познач нулі чисельника і знаменника на одній прямій.
4. На кожному інтервалі візьми пробне число та визнач знак дробу.
5. Вибери потрібні знаки. При ≥ або ≤ додай дозволені нулі чисельника. Нулі знаменника виключи завжди.

Червоний порожній кружечок на схемах — заборонена точка знаменника. Зафарбований зелений — дозволений нуль чисельника, який входить у відповідь.

4. Чотири приклади

1. \(\frac{x+2}{x-5}>0\)

ОДЗ: \(x\ne5\).
Нуль чисельника: −2. Нуль знаменника: 5.
Пробні числа: −3 → +; 0 → −; 6 → +.
\[x\in(-\infty;-2)\cup(5;+\infty)\]

Вибираємо зовнішні інтервали. Обидві крайні точки виключаємо.

2. \(\frac{x+2}{x-5}<0\)

ОДЗ: \(x\ne5\).
Нуль чисельника: −2. Нуль знаменника: 5.
Пробні числа: −3 → +; 0 → −; 6 → +.
\[x\in(-2;5)\]

Вибираємо середній інтервал. Обидві крайні точки виключаємо.

3. \(\frac{x+2}{x-5}\ge0\)

ОДЗ: \(x\ne5\).
Нуль чисельника: −2. Нуль знаменника: 5.
Пробні числа: −3 → +; 0 → −; 6 → +.
\[x\in(-\infty;-2]\cup(5;+\infty)\]

Вибираємо зовнішні інтервали. Точку −2 включаємо, а 5 виключаємо.

4. \(\frac{x+2}{x-5}\le0\)

ОДЗ: \(x\ne5\).
Нуль чисельника: −2. Нуль знаменника: 5.
Пробні числа: −3 → +; 0 → −; 6 → +.
\[x\in[-2;5)\]

Вибираємо середній інтервал. Точку −2 включаємо, а 5 виключаємо.

5. Лайфхаки та типові помилки

Не скорочуй ОДЗ: \(\frac{x-2}{x-2}=1\) лише при \(x\ne2\). Для ≥ 0 відповідь — усі числа, крім 2.

Кратність: біля множника непарного степеня знак змінюється, парного — не змінюється. Це працює і для чисельника, і для знаменника.

Перевір точку: знак ≤ не робить нуль знаменника дозволеним. Для \(\frac{(x+1)^2}{(x-2)^2}>0\) виключаємо і −1 (нуль), і 2 (ОДЗ).

Знайди помилку: учень отримав [−2;5] для дробу ≤ 0

Права дужка має бути круглою: знаменник при x = 5 нуль. Правильна відповідь [−2;5).

Лабораторія знаків дробу

Досліди (x−a)/(x−b). Змінюй точки a, b та знак. Спробуй a = b.

Тренажер: 18 нерівностей за рівнями

Записуй відповідь проміжком: (-inf;5), [-1;1]. Для об’єднання: (-inf;2) U (3;inf). Одна точка: {2}. Особливі випадки: всі або немає.

Можна вводити ∞ замість inf, дроби 1/2 та корені sqrt(2). Десяткові дроби — з комою або крапкою. Межі відділяй крапкою з комою.

Гра «Збережи ОДЗ!»

Обери правильне перетворення. Вісім раундів.

Перевір себе: 10 завдань

Вводь проміжки, як у тренажері. Для відсутності розв’язків напиши «немає», для всіх дійсних чисел — «всі». Відповіді й пояснення з’являться після завершення.

Домашнє завдання

1. Розв’яжи \(\frac{(x-1)}{(x+3)}>0\).

Розв’язання та відповідь

1. ОДЗ: \(x\ne -3\).
2. Критичні точки: -3, 1.
3. Знаки зліва направо: +; −; +.
4. Знак строгий: нулі не включаємо. Нулі знаменника завжди виключаємо.
Відповідь: (-inf;-3) U (1;inf).

2. Розв’яжи \(\frac{x}{(x-2)}\ge0\).

Розв’язання та відповідь

1. ОДЗ: \(x\ne 2\).
2. Критичні точки: 0, 2.
3. Знаки зліва направо: +; −; +.
4. Нулі чисельника можна включити, якщо вони належать ОДЗ. Нулі знаменника завжди виключаємо.
Відповідь: (-inf;0] U (2;inf).

3. Розв’яжи \(\frac{(x+1)(x-2)}{(x-4)}>0\).

Розв’язання та відповідь

1. ОДЗ: \(x\ne 4\).
2. Критичні точки: -1, 2, 4.
3. Знаки зліва направо: −; +; −; +.
4. Знак строгий: нулі не включаємо. Нулі знаменника завжди виключаємо.
Відповідь: (-1;2) U (4;inf).

4. Розв’яжи \(\frac{(x-1)}{(x-2)(x-3)}\ge0\).

Розв’язання та відповідь

1. ОДЗ: \(x\ne 2,\ x\ne 3\).
2. Критичні точки: 1, 2, 3.
3. Знаки зліва направо: −; +; −; +.
4. Нулі чисельника можна включити, якщо вони належать ОДЗ. Нулі знаменника завжди виключаємо.
Відповідь: [1;2) U (3;inf).

5. Розв’яжи \(\frac{(x-2)}{(x-2)}\le0\).

Розв’язання та відповідь

1. ОДЗ: \(x\ne 2\).
2. Критичні точки: 2.
3. Знаки зліва направо: +; +.
4. Нулі чисельника можна включити, якщо вони належать ОДЗ. Нулі знаменника завжди виключаємо.
Відповідь: none.

6. Розв’яжи \(\frac{(x+1)(x+1)}{(x-2)(x-2)}>0\).

Розв’язання та відповідь

1. ОДЗ: \(x\ne 2\).
2. Критичні точки: -1, 2.
3. Знаки зліва направо: +; +; +.
4. Знак строгий: нулі не включаємо. Нулі знаменника завжди виключаємо.
Відповідь: (-inf;-1) U (-1;2) U (2;inf).
