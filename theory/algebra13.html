Ірраціональні нерівності

ОДЗ • корені • рівносильні системи • перевірка знаків

1. Корінь і область визначення

Ірраціональна нерівність містить змінну під знаком кореня або в основі степеня з раціональним показником. Спершу визнач, де всі вирази існують.

\[\sqrt{f(x)}\text{ існує, коли }f(x)\ge0;\qquad \sqrt{f(x)}\ge0\]

Непарний корінь визначений для будь-якого дійсного підкореневого значення. Наприклад, \(\sqrt[3]{-8}=-2\). Важливо: \(\sqrt{x^2}=|x|\), а не завжди x.

Додавання й віднімання однакового числа зберігають знак нерівності. Множення або ділення на додатне число теж зберігає знак, а на від’ємне — змінює його. На нуль ділити не можна.

2. Два квадратні корені

\[\sqrt{f(x)}\ge\sqrt{g(x)}\iff\begin{cases}f(x)\ge g(x)\\g(x)\ge0\end{cases}\]

Тут f ≥ 0 випливає з f ≥ g ≥ 0. Для строгого > заміни перший знак на >. Для < або ≤ потрібно вимагати f ≥ 0 та порівняти f із g: тоді невід’ємність g випливає автоматично.

Приклад 1

\[\sqrt{x^2-3x+1}\ge\sqrt{3x-4}\]
1. Порівнюємо підкореневі вирази та зберігаємо невід’ємність правого: \(x^2-6x+5\ge0\), \(x\ge\frac43\).
2. \((x-1)(x-5)\ge0\): \(x\le1\) або \(x\ge5\).
3. Перетинаємо із \(x\ge\frac43\). Ліва гілка зникає.
\[x\in[5;+\infty)\]

3. Корінь менший за вираз

\[\sqrt f<g\iff\begin{cases}f\ge0\\g>0\\f<g^2\end{cases}\]

Чому g > 0? Корінь невід’ємний, тож він може бути строго меншим лише за додатне число. Квадратуємо тільки після перевірки знаків.

Приклад 2

\[\sqrt{2x^2-3x-5}<x-1\]
1. ОДЗ: \((2x-5)(x+1)\ge0\), тобто \(x\le-1\) або \(x\ge\frac52\).
2. Права частина додатна: \(x>1\).
3. Квадратуємо: \(2x^2-3x-5<(x-1)^2\). Отримуємо \((x-3)(x+2)<0\): \(-2<x<3\).
4. Перетин усіх трьох умов:
\[x\in\left[\frac52;3\right)\]

Ліва межа входить: корінь там дорівнює 0, а права частина 1,5. Права межа не входить: обидві частини там рівні 2.

4. Корінь більший за вираз: дві гілки

\[\sqrt f>g\iff\left[\begin{array}{l}\begin{cases}g<0\\f\ge0\end{cases}\\[6pt]\begin{cases}g\ge0\\f>g^2\end{cases}\end{array}\right.\]

Гілка 1: якщо g < 0, будь-який визначений корінь більший за g. Достатньо ОДЗ. Гілка 2: якщо g ≥ 0, квадратування рівносильне. Результати двох гілок об’єднуємо; умови всередині гілки перетинаємо.

Приклад 3

\[\sqrt{x^2+7x+12}>6-x\]
ОДЗ: \((x+3)(x+4)\ge0\): \(x\le-4\) або \(x\ge-3\).
Гілка 1: \(6-x<0\Rightarrow x>6\). Усі ці числа належать ОДЗ.
Гілка 2: \(x\le6\), \(x^2+7x+12>(6-x)^2\). Звідси \(19x>24\), тобто \(x>\frac{24}{19}\). ОДЗ тут виконується. Отримуємо \((\frac{24}{19};6]\).
\[x\in\left(\frac{24}{19};6\right]\cup(6;+\infty)=\left(\frac{24}{19};+\infty\right)\]

5. Нестрогі знаки: перевір нуль

\[\sqrt f\le g\iff\begin{cases}f\ge0\\g\ge0\\f\le g^2\end{cases}\]\[\sqrt f\ge g\iff\left[\begin{array}{l}\begin{cases}g\le0\\f\ge0\end{cases}\\[6pt]\begin{cases}g>0\\f\ge g^2\end{cases}\end{array}\right.\]

При ≥ у першій гілці g = 0 дозволене: будь-який корінь ≥ 0. Для < нуль праворуч неможливий; для ≤ можливий лише нуль кореня.

6. Пам’ятка для рівнянь із коренями

Це два незалежні випадки, а не послідовні кроки:

\[\sqrt[2n+1]{x}=a\iff x=a^{2n+1}\quad(a\in\mathbb R)\]
\[\sqrt[2n]{x}=a\iff\begin{cases}x=a^{2n}\\a\ge0\end{cases}\]

Для парного кореня: a < 0 — розв’язків немає; a = 0 — x = 0; a > 0 — x = a2n. Для непарного кореня від’ємне a допустиме. У цих формулах n — натуральне число.

7. Лайфхаки та пошук помилок

Перед квадратуванням постав два запитання: «Чи існує корінь?» і «Який знак має права частина?». Для системи беремо перетин; для двох альтернативних гілок — об’єднання.

Учень: √x > −2 ⇒ x > 4. Де помилка?

Права частина від’ємна, тому квадратування не рівносильне. Насправді підходять усі x ≥ 0.

Учень: √(x²) = x. Чи завжди?

Ні. При x = −3 маємо √9 = 3. Правильно: √(x²) = |x|.

Лабораторія: √(x−a) порівняно з b

Зміни b на −1, 0, 2. Порівняй усі чотири знаки. Чому випадок b < 0 не потребує квадратування?

Тренажер: 18 нерівностей за рівнями

Записуй відповідь проміжком: (-inf;5), [-1;1]. Для об’єднання: (-inf;2) U (3;inf). Одна точка: {2}. Особливі випадки: всі або немає.

Можна вводити ∞ замість inf, дроби 1/2 та корені sqrt(2). Десяткові дроби — з комою або крапкою. Межі відділяй крапкою з комою.
