Первісна та інтеграл: повертаємося від похідної

1. Первісна — зворотний шлях

F — первісна для f на проміжку, якщо \(F'(x)=f(x)\) для кожного x цього проміжку.

Похідна x³ дорівнює 3x². Отже x³ — первісна для 3x².

Інтегрування допомагає відновити функцію за швидкістю її зміни. Якщо v(t) — швидкість, первісна дає положення з точністю до початкової координати.

Найнадійніша перевірка: продиференціюй відповідь. Маєш отримати початкову підінтегральну функцію.

2. Навіщо потрібна стала C?

Похідні x³, x³ + 5 та x³ − 10 однакові: 3x². Стала зникає при диференціюванні.

На одному проміжку всі первісні відрізняються сталою. Невизначений інтеграл — сімейство всіх первісних:

\[\int f(x)\,dx=F(x)+C,\qquad C\in\mathbb R\]

dx указує змінну інтегрування. C не залежить від x. Щоб знайти конкретну первісну, потрібна додаткова умова.

F′(x) = 2x, F(1) = 5. F(x) = x² + C; 1 + C = 5 → C = 4.

3. Степені, константи й виняток

\[\int0\,dx=C,\qquad\int1\,dx=x+C\]\[\int x^n\,dx=\frac{x^{n+1}}{n+1}+C\quad(n\ne-1)\]

Степінь збільшуємо на 1, ділимо на новий степінь. Формулу застосовуємо на проміжку, де відповідний степінь визначений.

\(\int x^2dx=\frac{x^3}3+C\).
\(\int\sqrt{x}\,dx=\int x^{1/2}dx=\frac23x^{3/2}+C\) на x > 0.
\(\int\frac1{x^2}dx=-\frac1x+C\), x ≠ 0, на кожному проміжку області визначення.

Для n = −1 знаменник n + 1 дорівнює нулю. Тут окрема формула:

\[\int\frac{dx}{x}=\ln|x|+C\]

Модуль потрібний для від’ємних x. На (−∞;0) та (0;+∞) сталі можуть бути різними.

4. Тригонометричні та показникові формули

\[\int\sin x\,dx=-\cos x+C\]\[\int\cos x\,dx=\sin x+C\]\[\int\frac{dx}{\cos^2x}=\tan x+C\]\[\int\frac{dx}{\sin^2x}=-\cot x+C\]\[\int e^x\,dx=e^x+C\]\[\int a^x\,dx=\frac{a^x}{\ln a}+C\quad(a>0,\ a\ne1)\]

Для тангенса та котангенса вибираємо проміжок без нулів відповідного знаменника. Тригонометричні аргументи — у радіанах.

При a = 1 підінтегральна функція дорівнює 1, тому інтеграл x + C.

Знаки перевір похідною: (−cos x)′ = sin x; (−cot x)′ = 1/sin²x.

5. Лінійність: розбери складний вираз

\[\int(\alpha f(x)+\beta g(x))dx=\alpha F(x)+\beta G(x)+C\]

Сталі множники виносимо, суму інтегруємо почленно.

\(\int(3x^2-4x+2)dx\).
3 · x³/3 − 4 · x²/2 + 2x + C.
\[x^3-2x^2+2x+C\]

Достатньо однієї довільної сталої C. Інтеграл добутку загалом не дорівнює добутку інтегралів.

6. Лінійний аргумент: не забудь поділити

Якщо F′ = f та k ≠ 0:

\[\int f(kx+b)dx=\frac1kF(kx+b)+C\]

Похідна внутрішнього виразу дає множник k, тому при інтегруванні компенсуємо його діленням.

\(\int\cos(3x)dx=\frac13\sin(3x)+C\).
\(\int e^{2x+1}dx=\frac12e^{2x+1}+C\).
\(\int(2x+1)^3dx=\frac{(2x+1)^4}{8}+C\).

При k = 0 підінтегральна функція стала f(b): інтеграл f(b)x + C.

7. Визначений інтеграл: результат — число

Якщо f неперервна на [a;b] і F′ = f, формула Ньютона–Лейбніца:

\[\int_a^bf(x)dx=F(b)-F(a)\]
\(\int_0^2 3x^2dx=[x^3]_0^2=8-0=8\).

Стала C скорочується. При однакових межах інтеграл 0; перестановка меж змінює знак.

Для f ≥ 0 та a ≤ b інтеграл дорівнює площі під графіком. Якщо графік нижче OX, внесок від’ємний.

Геометрична площа: \(S=\int_a^b|f(x)|dx\). Наприклад, інтеграл x від −1 до 1 дорівнює 0, а площа між графіком і OX — 1.

8. Лайфхаки та самоперевірка

🔙 «Плюс один до степеня — поділи на новий степінь».

➕ У невизначеному інтегралі додавай C. У визначеному відповідь число.

🧩 Заміни корені та дроби степенями, якщо це зручно.

🎯 Для складеного лінійного аргументу врахуй його похідну.

Знайди помилку: ∫x² dx = 2x + C

Це похідна x². Правильна первісна x³/3 + C.

Знайди помилку: ∫cos(2x) dx = sin(2x) + C

Похідна відповіді 2cos(2x). Треба (1/2)sin(2x) + C.

Лабораторія сімейства первісних

Для f(x) = 2x первісні F(x) = x² + C. Зміна C рухає параболу вгору або вниз, а похідна залишається 2x.

Сіра парабола — x², фіолетова — x² + C. Крок сітки 1. Частини за межами вікна обрізані.

Перевір себе: 10 запитань

Розв’язання з’являться після завершення тесту.

Домашня практика

1. Знайди \(\int(4x^3-6x+1)dx\).

2. Знайди \(\int\sin(2x)dx\).

3. F′(x) = 3x², F(1) = 4. Знайди F.

4. Обчисли \(\int_0^3 2xdx\).

5. Обчисли \(\int_0^\pi\sin xdx\).

6. Поясни різницю між інтегралом x на [−2;2] та площею між графіком і OX.

Розв’язання

1. x⁴ − 3x² + x + C.

2. \(-\frac12\cos(2x)+C\).

3. F = x³ + C; 1 + C = 4, тому F = x³ + 3.

4. [x²]₀³ = 9.

5. [−cos x]₀ᵖⁱ = 1 − (−1) = 2.

6. Інтеграл 0; площа 4: два трикутники з катетами 2.
