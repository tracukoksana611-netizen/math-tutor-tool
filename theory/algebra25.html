1. Три сигнали похідної

Додатна похідна — графік піднімається, якщо рухатися вправо. Від’ємна — опускається.

\[f'(x)>0\Rightarrow f\text{ зростає};\qquad f'(x)<0\Rightarrow f\text{ спадає}.\]

Ці умови мають виконуватися в кожній точці досліджуваного відкритого інтервалу. Якщо похідна дорівнює нулю на всьому інтервалі, функція стала.

Одна нульова похідна не означає сталу функцію! Для x³ похідна у 0 дорівнює 0, але функція зростає.

2. Критична точка: кандидат, а не готова відповідь

Критична точка — внутрішня точка області визначення, де похідна дорівнює 0 або не існує.

Приклад: x² має критичну точку 0 через нульову похідну; |x| — через злам. В обох випадках є мінімум. Для x³ у 0 екстремуму немає.

Точка, де функція не визначена, не є її критичною точкою. Для 1/x число 0 — розрив області визначення.

3. Алгоритм монотонності

1. Знайди область визначення.
2. Обчисли похідну.
3. Знайди її нулі, точки неіснування та розриви області визначення.
4. Розділи числову пряму на інтервали. Перевір знак похідної в кожному.
5. Запиши: «+» → зростає, «−» → спадає.

Підстановка однієї пробної точки працює, коли всередині інтервалу похідна не може змінити знак, наприклад вона неперервна й не має там нулів.

4. Покроковий приклад: x³ − 27x − 4

1. Поліном визначений для всіх дійсних x.
\[f'(x)=3x^2-27=3(x-3)(x+3).\]
2. f′(x) = 0 при x = −3 і x = 3.
3. Ліворуч від −3 обидва множники від’ємні: добуток додатний. Між −3 і 3 знаки різні: добуток від’ємний. Праворуч від 3 обидва додатні.
ІнтервалЗнак f′Рух
\((−\infty;-3)\)+↗ Зростає
(−3;3)−↘ Спадає
\((3;+\infty)\)+↗ Зростає

За неперервністю можна включити крайні точки: зростає на \((−\infty;-3]\) та \([3;+\infty)\), спадає на [−3;3]. Краще називати ці два проміжки зростання окремо.

5. Максимум та мінімум: подивись на зміну знака

Якщо функція неперервна в критичній точці:

+ → −: підйом змінюється спуском → локальний максимум.
− → +: спуск змінюється підйомом → локальний мінімум.
+ → + або − → −: екстремуму немає.

Для попереднього прикладу:

\[x_{\max}=-3,\quad f(-3)=50;\qquad x_{\min}=3,\quad f(3)=-58.\]

Абсциса максимуму −3, значення максимуму 50; точка графіка (−3;50). Не плутай ці три відповіді.

Локальний максимум — найвище значення поблизу точки. Це не обов’язково найбільше значення на всій області: наш кубічний поліном необмежений зверху й знизу.

6. Повне дослідження функції

1. Область визначення, неперервність, розриви.
2. Перевір парність: f(−x) = f(x); непарність: f(−x) = −f(x). Область має бути симетрична відносно 0. Для тригонометричних функцій з’ясуй період.
3. Перетини з осями: y = f(0), якщо 0 допустимий; корені f(x) = 0.
4. Похідна, критичні точки, знаки, монотонність, екстремуми.
5. Додаткові точки, поведінка на краях області, за потреби асимптоти.
6. Побудуй графік, узгоджений з усіма висновками.

Для x³ − 27x − 4 перетин OY: (0;−4); функція ні парна, ні непарна. Корені приблизно −5,1204; −0,1483; 5,2687. Графік має центр симетрії (0;−4).

7. Найбільше й найменше на відрізку

Для неперервної функції на замкненому відрізку [a;b] перевір критичні точки всередині та обидва кінці. Порівняй значення.

f(x) = x³ − 27x − 4 на [−4;4]: f(−4) = 40, f(−3) = 50, f(3) = −58, f(4) = −48.

Отже найбільше значення 50, найменше −58. На [−1;1] критичних точок немає: максимум f(−1) = 22, мінімум f(1) = −30.

8. Лайфхаки для самоперевірки

🧩 Розкладай похідну на множники — знаки видно швидше.

🔍 Нуль похідної з парною кратністю зазвичай не змінює знак; перевір сусідні інтервали.

🎯 Спочатку знайди x екстремуму, потім підстав його саме у f, щоб отримати y.

🚧 Розрив області визначення розділяє проміжки. Функція 1/x спадає на кожному з двох проміжків, але не на їх об’єднанні.

📈 Графік — перевірка висновків, а не заміна обчислень. Масштаб осей може змінювати враження від крутизни.

Лабораторія: f(x) = x³ − 3ax − 4

Змінюй a. При a > 0 є два екстремуми. При a = 0 похідна має нуль, але екстремуму немає. При a < 0 функція всюди зростає.

Фіолетовий графік f, зелена крива f′. Вертикальні пунктири показують критичні абсциси; позначки на f — екстремуми. Масштаб y підлаштовується до параметра.

Гра «Обери формулу»

Обери формулу, яка безпосередньо використовує наведені дані. Вісім раундів.

Перевір себе: 10 запитань

Розв’язання з’являться після завершення тесту.

Домашня практика

1. Досліди x² − 6x + 5 на монотонність та екстремуми.

2. Досліди x³ − 12x.

3. Чи є екстремум у x⁵ при x = 0?

4. Знайди найменше та найбільше x² − 6x + 5 на [0;4].

5. Досліди 1/x: область, похідна, монотонність.

6. Побудуй графік x³ − 27x − 4 за алгоритмом із теорії.

Пояснення й відповіді

1. f′ = 2x − 6: спадає до 3, зростає після 3; мінімум f(3) = −4. Корені 1 і 5.

2. f′ = 3(x − 2)(x + 2). Зростає до −2 і після 2; спадає між ними. Максимум f(−2) = 16, мінімум f(2) = −16.

3. Ні. 5x⁴ ≥ 0, знак не змінюється.

4. f(0) = 5, f(3) = −4, f(4) = −3. Мінімум −4, максимум 5.

5. x ≠ 0; \(f'=-\frac1{x^2}<0\). Спадає окремо на \((−\infty;0)\) і \((0;+\infty)\). Екстремумів немає.

6. Звір перетин (0;−4), максимум (−3;50), мінімум (3;−58), три корені та стрілки руху.
