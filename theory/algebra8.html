Цілі рівняння

Лінійні • квадратні • Вієта • біквадратні

1. Що означає розв’язати рівняння?

Корінь рівняння — число, яке після підстановки замість x робить рівність правильною. Розв’язати рівняння — знайти всі його корені або довести, що їх немає.

У цілому рівнянні змінна не стоїть у знаменнику. Ми працюємо з дійсними числами. Дробові коефіцієнти дозволені: \(\frac12x+3=0\) — ціле рівняння.

«Ціле рівняння» не означає «лише цілі корені». Коренем може бути дріб або ірраціональне число.

Рівняння схоже на терези

Щоб зберегти рівність, виконуй однакову дію з обома частинами: додай чи відніми те саме число, помнож чи поділи на те саме ненульове число.

\[2x+3=11\quad\Rightarrow\quad2x=8\quad\Rightarrow\quad x=4\]

«Перенести доданок зі зміною знака» означає відняти цей доданок з обох частин.

2. Лінійні рівняння: ax = b

\[ax=b\]

a і b — відомі числа, x — змінна. Перед діленням завжди перевір a.

Якщо a ≠ 0: є один корінь \(x=\frac ba\).
Якщо a = 0, b ≠ 0: рівність \(0\cdot x=b\) неможлива — коренів немає.
Якщо a = 0, b = 0: рівність \(0\cdot x=0\) правильна для будь-якого дійсного x.

Приклад: −9x = 36

1. Коефіцієнт −9 не дорівнює нулю, тому ділимо обидві частини на −9.
\[x=\frac{36}{-9}=-4\]
2. Перевірка: \((-9)\cdot(-4)=36\). Відповідь: −4.

Приклад із дужками

\[3(x-2)=2x+5\]
1. Розкриваємо дужки: \(3x-6=2x+5\).
2. Віднімаємо 2x, додаємо 6: \(x=11\).
3. Перевіряємо: \(3(11-2)=27\) та \(2\cdot11+5=27\).
Не діли на x без перевірки x = 0: так можна втратити корінь. Не діли на коефіцієнт, якщо він може дорівнювати нулю.

3. Квадратне рівняння і дискримінант

\[ax^2+bx+c=0,\qquad a\ne0\]

Коефіцієнти a, b, c записуємо разом зі знаками. У рівнянні \(2x^2-5x-3=0\): a = 2, b = −5, c = −3.

\[D=b^2-4ac\]
D > 0: два різні дійсні корені.
\[x_1=\frac{-b+\sqrt D}{2a},\qquad x_2=\frac{-b-\sqrt D}{2a}\]
D = 0: один дійсний корінь.
\[x=\frac{-b}{2a}\]
D < 0: дійсних коренів немає.

На графіку корені — координати x точок, де парабола перетинає або торкається осі x. Відкрий лабораторію, щоб побачити всі три випадки.

Приклад: 2x² − 5x − 3 = 0

1. a = 2, b = −5, c = −3.
\[D=(-5)^2-4\cdot2\cdot(-3)=25+24=49\]
2. D > 0, тому шукаємо два корені.
\[x_1=\frac{5+7}{4}=3,\qquad x_2=\frac{5-7}{4}=-\frac12\]
3. Перевірка першого: \(2\cdot3^2-5\cdot3-3=0\). Другого: \(2\cdot\frac14+\frac52-3=0\).
У формулі коренів −b — число, протилежне b. Якщо b = −5, то −b = 5. Увесь чисельник ділимо на 2a.

4. Неповні квадратні: можна швидше!

Немає вільного члена: винеси x

\[x^2-5x=0\quad\Rightarrow\quad x(x-5)=0\]

Добуток дорівнює нулю, коли хоча б один множник дорівнює нулю: x = 0 або x = 5.

Немає лінійного члена: ізолюй квадрат

\[x^2-9=0\quad\Rightarrow\quad x^2=9\quad\Rightarrow\quad x=\pm3\]

Не забудь від’ємний корінь: \((-3)^2=9\). Але з \(x^2=-9\) дійсних коренів не буде.

Залишився лише квадрат

\[7x^2=0\quad\Rightarrow\quad x=0\]

5. Теорема Вієта: сума й добуток

Для зведеного квадратного рівняння коефіцієнт при квадраті дорівнює 1.

\[x^2+px+q=0\quad\Rightarrow\quad x_1+x_2=-p,\quad x_1x_2=q\]

Сума коренів — другий коефіцієнт із протилежним знаком. Добуток — вільний член.

x² − 5x + 6 = 0

1. Потрібні два числа з добутком 6 і сумою 5.
2. Пари: 1 і 6 дають суму 7; 2 і 3 дають суму 5.
\[x_1=2,\quad x_2=3;\qquad 2+3=5,\quad2\cdot3=6\]

Можна перевірити розкладанням:

\[x^2-5x+6=(x-2)(x-3)\]

А якщо a ≠ 1?

\[ax^2+bx+c=0:\qquad x_1+x_2=-\frac ba,\qquad x_1x_2=\frac ca\]

У прикладі \(2x^2-5x-3=0\) корені 3 і \(-\frac12\): сума \(\frac52\), добуток \(-\frac32\).

Вієта зручна для перевірки й підбору простих коренів. Якщо підбір не вдається, обчисли дискримінант. Для від’ємного D дійсної пари коренів немає.

6. Біквадратні рівняння: заміна x² = t

\[ax^4+bx^2+c=0,\qquad a\ne0\]

Є четвертий і другий степені, але немає першого та третього. Замінимо \(x^2=t\). Тоді \(x^4=t^2\).

Для дійсного x обов’язково t ≥ 0! Від’ємний корінь рівняння для t не дає дійсних значень x.

x⁴ − 6x² − 7 = 0

1. Заміна: \(t=x^2\), \(t\ge0\).
\[t^2-6t-7=0\]
2. За Вієтом або через D: t = 7 чи t = −1.
3. Повертаємося до x. Із t = 7 отримуємо два корені, а t = −1 відкидаємо.
\[x^2=7\Rightarrow x=\pm\sqrt7;\qquad x^2=-1\Rightarrow\text{дійсних коренів немає}\]

Відповідь: \(-\sqrt7;\sqrt7\).

Скільки коренів може бути?
t > 0 → два корені \(\pm\sqrt t\).
t = 0 → один корінь x = 0.
t < 0 → жодного дійсного кореня.

Наприклад, \(x^4-5x^2+4=0\) дає t = 1 і t = 4, тому чотири корені: −2, −1, 1, 2.

7. Лайфхаки та типові помилки

Спочатку приведи рівняння до стандартного вигляду. Потім випиши коефіцієнти зі знаками.
У \(x^2=16\) відповідь не лише 4: корені −4 і 4.
У \(x(x-5)=0\) не скорочуй на x: корінь x = 0 загубиться.
Якщо q < 0 у зведеному квадратному рівнянні, дійсні корені мають різні знаки.
Якщо q > 0 та є дійсні корені, вони одного знака; їхній знак підкаже сума −p.
У біквадратному рівнянні не закінчуй на t: повернися до x.
Перевір знайдені корені підстановкою в початкове рівняння.

Знайди помилку учня

Учень розв’язав \(x^4-5x^2+4=0\), знайшов t = 1 і t = 4 та записав x = 1 і x = 4.

Пояснення

t — це квадрат x. Потрібно розв’язати \(x^2=1\) та \(x^2=4\). Отже, x = −2, −1, 1, 2. Учень не виконав зворотну заміну.

Графічна лабораторія: де живуть корені?

Розглядаємо \(ax^2+bx+c=0\). Корені — координати x точок графіка \(y=ax^2+bx+c\), у яких y = 0.

Досліди самостійно

1. Обери «Два корені». Знайди на осі x числа 2 і 3.

2. Обери «Один корінь». Чим дотик відрізняється від перетину?

3. Обери «Без коренів». Чому парабола не досягає осі x?

4. Встанови a = 0. Чому графік уже не парабола?

Тренажер: 24 задачі за рівнями

Введи всі різні корені через крапку з комою, наприклад: −2; 3. Дріб: 1/2. Корінь: sqrt(7). Десяткове число: 0,5. Для особливих випадків напиши немає або всі.

Порядок коренів не важливий. Десяткові відповіді округлюй щонайменше до трьох знаків після коми.

Гра «Скільки коренів?»

Обери кількість різних дійсних коренів. Вісім раундів, пояснення після відповіді.

Перевір себе: 10 завдань

Вводь усі корені через крапку з комою. Якщо коренів немає, напиши «немає»; якщо підходить будь-яке дійсне число — «всі». До завершення тесту розв’язання приховані.

9. Чому у \(x^2=-4\) немає дійсних коренів, а у \(x^2=4\) їх два?

Відповіді та розв’язання

1. \(x=\frac{-21}{7}=-3\).

2. \(4x-4=2x+8\Rightarrow2x=12\Rightarrow x=6\).

3. Після віднімання 2x маємо 5 = −1. Коренів немає.

4. Сума 7, добуток 12: x = 3; 4.

5. \(x^2=4\Rightarrow x=\pm2\).

6. \((x+2)^2=0\Rightarrow x=-2\).

7. \(t=x^2\): \(t^2-10t+9=0\), t = 1; 9. Отже, x = −3; −1; 1; 3.

8. \(x^2(x^2+3)=0\). Дійсний корінь лише x = 0.

9. Квадрат дійсного числа невід’ємний. Числа 2 і −2 мають однаковий квадрат 4.
