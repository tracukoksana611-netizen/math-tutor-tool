Раціональні дроби: спочатку умови, потім дії

1. Які вирази називаємо раціональними?

Раціональні вирази утворені числами й змінними за допомогою додавання, віднімання, множення, ділення та натуральних степенів. Цілі вирази не містять ділення на вираз зі змінною. Дробові — містять.

\[2+a^2,\quad\frac{6(a+b)}7\quad\text{— цілі};\qquad\frac{4k+y}{3m-c},\quad x^2+x+\frac1x\quad\text{— дробові}.\]

Раціональний дріб має вигляд A/B, де A і B — многочлени, B не є нульовим многочленом. Числовий знаменник також можливий.

Тотожно рівні вирази мають однакові значення для всіх спільних допустимих значень змінних.

\[2x^2-18=(2x+6)(x-3).\]

2. ОДЗ: знаменник ніколи не нуль

Область допустимих значень — значення змінних, за яких усі дії визначені.

a³ + b − 2: будь-які дійсні a,b.
\[\frac{m-2}m:\quad m\ne0.\]
\[x^{-3}+\frac2{x-5}=\frac1{x^3}+\frac2{x-5}:\quad x\ne0,\quad x\ne5.\]

Для ділення на дріб додатково перевір, що сам дільник не дорівнює нулю.

3. Скорочуємо множники, а не доданки

\[\frac{12-3x^2}{15x+30}=\frac{3(2-x)(2+x)}{15(x+2)}=\frac{2-x}5,\quad x\ne-2.\]
1. ОДЗ початкового дробу: x ≠ −2.
2. Розклади різницю квадратів: 4 − x² = (2 − x)(2 + x).
3. Поділи чисельник і знаменник на спільні множники 3 та x + 2.
Після скорочення x = −2 залишається забороненим. Спрощена формула має значення в цій точці, а початковий дріб — ні.

У дробі (x + 2)/(x + 3) не можна «скоротити x»: він доданок, не множник усього чисельника й знаменника.

4. Мінус у дробі

\[\frac AB=\frac{-A}{-B};\qquad\frac{-A}B=\frac A{-B}=-\frac AB.\]

Зміна знаків обох частин не змінює дріб. Зміна знака лише однієї — змінює знак дробу.

\[\frac{x-2}{2-x}=-1\quad(x\ne2).\]

Бо 2 − x = −(x − 2). Мінус перед дужками змінює знак кожного доданка!

5. Спільний знаменник: алгоритм

1. Розклади кожен знаменник на множники.
2. Візьми всі різні множники з найбільшими потрібними степенями.
3. Для кожного дробу знайди додатковий множник: спільний знаменник / його знаменник.
4. Помнож на нього і чисельник, і знаменник.
\[\frac1{x(x-1)}+\frac1{x^2}:\quad Q=x^2(x-1),\quad x\ne0,1.\]

Додаткові множники відповідно x та x − 1. Зайві повторні множники не потрібні.

6. Додавання та віднімання: приклад

\[\frac{a^2-2b}{a^2-b^2}-\frac a{a+b}\]
1. a² − b² = (a − b)(a + b); ОДЗ a ≠ b, a ≠ −b.
2. Для другого дробу додатковий множник a − b.
\[\frac{a^2-2b-a(a-b)}{a^2-b^2}=\frac{a^2-2b-a^2+ab}{a^2-b^2}=\frac{ab-2b}{a^2-b^2}.\]

Мінус віднімає весь чисельник другого дробу: спочатку постав дужки, потім розкривай.

7. Множення: спочатку скороти

\[\frac{2a^2}x\cdot\frac y{6ah}=\frac{2a^2y}{6ahx}=\frac{ay}{3hx}.\]

ОДЗ початкового виразу: x ≠ 0, a ≠ 0, h ≠ 0. Навіть після скорочення a = 0 не дозволяється.

Скорочуємо множник 2a в чисельнику та знаменнику добутку. Складати спільний знаменник для множення не потрібно.

8. Ділення: переверни тільки дільник

\[\frac{A_1}{B_1}:\frac{A_2}{B_2}=\frac{A_1B_2}{B_1A_2},\quad B_1\ne0,\ B_2\ne0,\ A_2\ne0.\]
\[\frac{16x^3}{a+7}:\frac{12xy}{a^2-49}=\frac{16x^3(a-7)(a+7)}{(a+7)12xy}=\frac{4x^2(a-7)}{3y}.\]

ОДЗ: a ≠ ±7, x ≠ 0, y ≠ 0. Умова x,y ≠ 0 виникає, бо дільник має бути ненульовим.

Перевертаємо другий дріб і замінюємо ділення множенням. Перший дріб не перевертаємо.

9. Піднесення дробу до степеня

\[\left(\frac AB\right)^n=\frac{A^n}{B^n}\quad(B\ne0,\ n\in\mathbb N).\]
\[\left(\frac{5mn^2}{3x^4}\right)^3=\frac{125m^3n^6}{27x^{12}},\quad x\ne0.\]

Підносимо до степеня кожен множник; показники степенів перемножуємо. Для від’ємного цілого степеня також потрібно A ≠ 0: (A/B)⁻² = B²/A². Степінь 0 дає 1 для ненульового дробу.

10. Самоперевірка

🚧 Запиши ОДЗ до скорочення.

🧩 Підкресли спільні множники. Не викреслюй доданки.

➖ Після віднімання перевір усі знаки.

🔍 Підстав одне допустиме число в початковий та кінцевий вираз. Різні значення означають помилку; одна успішна перевірка не замінює доведення.

Учень скоротив (x² − 1)/(x − 1) до x + 1 і дозволив x = 1. Де помилка?

Формула x + 1 правильна лише за початкової умови x ≠ 1. При x = 1 початковий дріб має 0/0.

Лабораторія: скорочення та «дірка» в графіку

(x² − 1)/(x − 1) = x + 1 лише при x ≠ 1. Досліди, чому точка (1;2) відсутня.

Тренажер: 18 задач за рівнями

Вводь одне число. Можна дроби 1/4, десяткові 0,25, корені sqrt(5) та pi для π.

Гра «Обери формулу»

Обери формулу, яка безпосередньо використовує наведені дані. Вісім раундів.

Перевір себе: 10 запитань

Розв’язання з’являться після завершення тесту.

Домашня практика

Спрости, запиши ОДЗ.

1. \(\frac{x^2-16}{x-4}\).

2. \(\frac{3-x}{x-3}\).

3. \(\frac1{x-2}+\frac1{x+2}\).

4. \(\frac{x^2-4}{3x}\cdot\frac{6x}{x+2}\).

5. \(\frac{x}{x-1}:\frac{x^2}{x^2-1}\).

6. \((\frac{2a}{3b^2})^3\).

Розв’язання та відповіді

1. x + 4, x ≠ 4.

2. −1, x ≠ 3.

3. \(\frac{2x}{x^2-4}\), x ≠ ±2.

4. 2(x − 2), x ≠ 0,−2.

5. \(\frac{x+1}x\), x ≠ −1,0,1.

6. \(\frac{8a^3}{27b^6}\), b ≠ 0.
