1. Квадратний корінь і арифметичний корінь

Квадратні корені числа 100 — 10 і −10, бо обидва квадрати дорівнюють 100. Але символ √ означає тільки невід’ємний арифметичний корінь.

\[\sqrt{100}=10,\qquad x^2=100\Rightarrow x=\pm10.\]

У дійсних числах √a визначений при a ≥ 0. √36 = 6; √(−36) не визначений. √0 = 0.

√9 = 3, а не ±3. Два знаки виникають у відповіді до рівняння x² = 9.

2. Парний та непарний показник

Непарний корінь існує для будь-якого дійсного підкореневого числа й зберігає знак: ∛(−8) = −2. Парний корінь потребує невід’ємного підкореневого виразу та сам невід’ємний.

\[\sqrt[2k+1]{a^{2k+1}}=a;\qquad\sqrt[2k]{a^{2k}}=|a|.\]

Тут a ∈ ℝ, k — натуральне число.

∛6³ = 6; ∛(−6)³ = −6.
√6² = 6; √(−6)² = 6.
\[\sqrt{(\sqrt3-2)^2}=|\sqrt3-2|=2-\sqrt3\]

Оскільки √3 < 2, вираз √3 − 2 від’ємний. Модуль змінює його знак.

\[\sqrt[5]{(\sqrt3-2)^5}=\sqrt3-2.\]

3. Властивість добутку

\[\sqrt[n]{ab}=\sqrt[n]a\cdot\sqrt[n]b\quad(a,b\ge0,\ n\ge2).\]
√(64 · 81) = √64 · √81 = 8 · 9 = 72.

Для непарного n ця властивість діє і для від’ємних a,b. Для парного n не розділяй добуток від’ємних чисел на два корені: √((−4)(−9)) = 6, але √(−4) та √(−9) не існують у ℝ.

Корінь суми не розкладається на суму коренів: √(9 + 16) = 5, тоді як √9 + √16 = 7.

4. Властивість частки

\[\sqrt[n]{\frac ab}=\frac{\sqrt[n]a}{\sqrt[n]b}\quad(a\ge0,\ b>0,\ n\ge2).\]
\[\frac{\sqrt{128}}{\sqrt2}=\sqrt{\frac{128}2}=8;\qquad\frac{\sqrt[3]{81}}{\sqrt[3]3}=\sqrt[3]{27}=3.\]

Знаменник не може бути нулем. Для непарного n дозволені будь-які дійсні a та b ≠ 0.

5. Корінь у степені

\[(\sqrt[n]a)^k=\sqrt[n]{a^k}\quad(a\ge0,\ n\ge2,\ k\in\mathbb N).\]
\[(\sqrt{81})^2=\sqrt{81^2}=81.\]

Не плутай квадрат кореня й корінь квадрата: (√a)² = a при a ≥ 0; √(a²) = |a| при будь-якому дійсному a.

6. Корінь із кореня

\[\sqrt[m]{\sqrt[n]a}=\sqrt[mn]a\quad(a\ge0,\ m,n\ge2).\]

Показники перемножуємо, а не додаємо.

\[\sqrt[5]{\sqrt a}=\sqrt[10]a;\qquad\sqrt[3]{\sqrt[7]b}=\sqrt[21]b.\]

Наприклад, √(∛64) = √4 = 2 = ⁶√64.

7. Скорочення показника кореня та степеня

\[\sqrt[nk]{a^k}=\sqrt[n]a\quad(a\ge0,\ n\ge2,\ k\in\mathbb N).\]
\[\sqrt[6]{a^3}=\sqrt a;\qquad\sqrt[15]{b^5}=\sqrt[3]b\quad(a,b\ge0).\]

Універсальна умова a ≥ 0 робить правило безпечним. Для від’ємних чисел перевір парність: ⁶√(−2)² = ∛2, тоді як ∛(−2) від’ємний.

8. Корінь як раціональний степінь

\[\sqrt[m]{a^n}=a^{\frac nm}\quad(a\ge0,\ m\ge2,\ n\in\mathbb N).\]
\[\sqrt[5]{a^3}=a^{\frac35},\quad\sqrt2=2^{\frac12},\quad\sqrt[3]2=2^{\frac13}.\]

Чисельник — степінь, знаменник — показник кореня. Для від’ємної основи раціональні степені потребують окремої домовленості та перевірки знаменника; тут правило використовуємо для a ≥ 0.

9. Як спрощувати: три корисні прийоми

Винеси повний квадрат: √72 = √(36 · 2) = 6√2.
Об’єднай подібні корені: 3√2 + 5√2 = 8√2; √2 + √3 так не об’єднуються.
\[\frac1{\sqrt2}=\frac{\sqrt2}2;\qquad\frac1{\sqrt3+1}=\frac{\sqrt3-1}2.\]

В останньому дробі множимо чисельник і знаменник на спряжений вираз √3 − 1.

Спочатку перевір існування коренів і ненульовий знаменник. Після перетворення перевір знак та піднеси результат до потрібного степеня.

Гра «Обери формулу»

Обери формулу, яка безпосередньо використовує наведені дані. Вісім раундів.

Перевір себе: 10 запитань

Розв’язання з’являться після завершення тесту.

Домашня практика

1. \(\sqrt{(-8)^2}\).

2. \(\sqrt[3]{-125}\).

3. \(\sqrt{50}+\sqrt8\).

4. \(\sqrt[4]{\sqrt{256}}\).

5. \(\frac1{\sqrt5-2}\).

6. \(\sqrt{(3-\sqrt{10})^2}\).

Розв’язання

1. |−8| = 8.

2. −5, бо (−5)³ = −125.

3. 5√2 + 2√2 = 7√2.

4. ⁸√256 = 2.

5. Множимо на √5 + 2: результат √5 + 2.

6. √10 > 3, тому |3 − √10| = √10 − 3.
